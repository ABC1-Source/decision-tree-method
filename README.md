# decision-tree-method · 决策树方法论

> 18 岁、刚高考完的学生，把"应试/学习/决策"的本质拆成决策树。
> 不是教你怎么记，是教你怎么"走"——每个领域都有一棵决策树，剥出来就能走。

## 这是什么

应试教育学的是"被显式化的决策树"：看到题 → 分类 → 排除 → 收敛到唯一路径 → 执行。
知识点是树的节点原料，决策链才是树的主干。

本 skill 把这套剥茧工序固化成可调用的规则：任何领域（应试、学新技能、分析问题、做决策）都能用它从碎片里剥出决策树。

## 为什么值得看

- **亲历者，不是理论家**：福建高考前 5%，数学考出高中最低分——"会做压轴题却考崩"的亲历者，最懂考试到底考什么
- **方法手搓，不是抄的**：核心示例（物理最值决策链）是自己做题时剥出来的，不是书里抄的
- **学生视角**：市面上讲学习的是老师/成年人，这个是刚考完的学生拆解"我怎么学"

## 用法

把 SKILL.md 喂给任意 AI 或自己按流程走：

- 学新东西从哪入手 → 目的 → 已有基础 → 排除 → 第一个正反馈动作
- 一道题不会做 → 看题型 → 列候选方法+适用条件 → 排除 → 收敛到唯一解法
- 判断"我该不该做 X" → 条件 → 推该条件下的最优选择

## 两个用途（为什么建这个仓库）

1. **自媒体**：18 岁高考生拆解"我怎么学"的内容资产——发 B站/知乎，亲历者视角
2. **产品落地**：高中数学模型树 = 学习产品的内容底座——每个模块一棵树，学生"看特征走路"
