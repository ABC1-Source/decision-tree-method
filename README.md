# decision-tree-method · 决策树方法论

> **一句话卖点**：18 岁、刚高考完的学生，把"怎么学、怎么做决策"拆成一棵**能走的树**——不是教你怎么记，是教你怎么"走"。

## 为什么值得看（亲历者，不是理论家）

- **高考前 5%，数学却考出高中最低分** —— "会做压轴题却考崩"的亲历者，最懂考试到底考什么：不是知识点，是**决策**。
- **方法手搓，不是抄的** —— 核心案例（物理最值决策链）是自己做题时一层层剥出来的，不是从书里搬的。
- **学生视角** —— 市面上讲"怎么学"的，是老师、是成年人；这个是刚考完的学生，拆解"我怎么学"。

## 这是什么

应试教育教的，本质是**被显式化的决策树**：看到题 → 分类 → 排除 → 收敛到唯一路径 → 执行。

- 知识点是树的**节点原料**；
- 决策链才是树的**主干**。

本仓库把这套"剥茧工序"固化成可调用的规则（一个 AI skill）。任何领域——应试、学新技能、分析问题、做决策——都能用它从碎片里剥出一棵自己的决策树。

## 结构图

**方法论主干（模型树）**

```
拿到问题
  └─ M0 入口分流：它问什么？属于哪类？
       └─ M1 列候选：所有能用的解法/路径（=技能点全集，一个不漏）
            └─ M2 排除：逐条对照适用条件，砍掉不适用的
                 └─ 收敛到唯一：条件命中的那条 = 你要走的路
                      └─ 执行 + 采分点/易错点复盘
```

> 决策树是"路牌"（已知 X 走 Y 路），模型树是"筛选器"（候选全列 → 逐条排除 → 收敛唯一）。应试/学习/决策里难的不是知道路，是判断该走哪条——所以模型树效率更高（已验证）。

## FAQ

**Q：这和普通"学习方法"有什么区别？**
A：不教你怎么记知识点，教你怎么在"多个候选方法里选对的那个"。考试 / 学习 / 决策的本质是决策，不是记忆。

**Q：模型树和决策树不一样吗？**
A：决策树是"路牌"（已知 X 走 Y 路），适合信息充分时快速路由；模型树是"筛选器"（候选全列 → 逐条排除 → 收敛唯一），适合"判断哪个方法适用"的场景。后者效率更高（已验证）。

**Q：我不是高中生，也能用这个方法吗？**
A：能。它适用于一切"多个候选选一个"的场景——学新技能、分析问题、做决策，不只是应试。

**Q：内容可信吗？**
A：核心案例是作者亲历手搓，且模型树经过四源教辅交叉验证（一数 / 朱昊鲲 / 21cnjy / 学科网），不是凭印象写的。
