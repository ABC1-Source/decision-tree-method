# 高中数学模块 · 模型树蒸馏全流程指令（v1）

> **用途**：给执行窗口的完整操作手册——按本流程蒸任意高中数学模块（数列/函数/复数/向量/不等式/立体/统计），产出与《解三角形决策树.md》（v9，已完成的范本）同格式的模型树文件。
> **核心纪律**：①先穷举后建模 ②资料区间锁死 ③能出题=可调用 ④证据与结论分文件。
> **范本**：`decision-tree-method/examples/高中数学/解三角形决策树.md`（v9）——每阶段做完对照范本自查。

---

## 总流程（一条主线，5 个阶段）

```
阶段0 锁资料区间 → 阶段1 穷举技能点 → 阶段2 建知识体系 → 阶段3 建模型树 → 阶段4 交叉验证+收尾
        （30分钟）      （核心，1h）         （1h）           （2h）          （1h）
```

**铁律：顺序不可乱。** 阶段1（穷举）没做完，禁止进阶段3（建模）——跳过穷举直接建模=必漏单本独有技能点（解三角形 v8→v9 的教训：比例问题/周长/外接圆全是被单列而漏掉的）。

## 阶段 0 · 锁资料区间（30 分钟）

### 做什么
1. 打开搜索引擎，抓以下 **四源教辅** 的模块目录/知识梳理（缺哪本补哪本，优先有目录全文的）：
   - **一数《必刷100讲·基础》/《高考数学核心方法》**（B站一数，模块→节→类型三级目录）
   - **朱昊鲲《真题全刷·基础2000》**（技能点式目录，如"4.1正弦/4.2余弦/4.3余弦变型…"）
   - **21cnjy 一轮复习讲义**（搜"高考数学一轮复习讲义 [模块名]"，《第04讲解三角形》类，含考情/题型/易错/课本典例）
   - **学科网专题**（搜"专题 [模块名] 解三角形 学科网"，《专题03》类，含知能/重难点/易混易错/方法技巧）
2. 锚点资料：人教 A 版教材对应章节 + 高考考纲 + 近 3 年真题（考情解码用）。

### 产出
- 四源教辅的模块目录原文（复制下来，标来源）

### 反模式（禁止）
- ❌ 搜"学习/方法论"类泛资料（区间外不翻）
- ❌ 拿模型记忆写目录（必须搜索+复制原文）

### 自查
- [ ] 四源目录都拿到了吗？缺哪本？（至少三源才可进阶段1，用户钦定标准）

## 阶段 1 · 穷举技能点（核心，1 小时）

### 做什么
1. **逐本列技能点**：把四源教辅的每个"节/题型/技能点"列成清单（像解三角形：正弦/余弦/余弦变型/比例/面积/边角互化/解的个数/判形状/图形/各种线/最值/实际应用/外接圆）
2. **合并去重 → 技能点全集**（并集，不丢任何一个单本独有的）
3. **逐项打勾**：每个技能点标它出现在哪几本（四源覆盖/三源/两源/单本独有）
4. **标注单列标记**：凡是某本**单独列成节/题型**的（如朱昊鲲4.3余弦变型、学科网题型6周长），标"▲单列"——**这类最容易漏，必须全部进模型**
5. 产出"技能点穷举清单"（表格：技能点 | 一数 | 朱昊鲲 | 21cnjy | 学科网 | 判定）

### 判定规则
- **★必学**：多源覆盖（≥2 源出现）
- **▲按需**：单源单列但送分高频（比例/外接圆）→ 进模型，标"▲"
- **▲中上**：单源且难度中上（各种线/最值）→ 进模型，标"选学"
- 最难判断的：单本单列且没在别处出现——**先假设它重要，宁可多进模型不漏**

### 反模式（禁止）
- ❌ 用模型框架反推技能点（应该用教辅内容填模型，不是用模型框教辅）
- ❌ 漏掉单本独有的"单列"项
- ❌ 凭记忆补技能点（清单必须来自四源原文）

### 自查
- [ ] 技能点全集数 ≥ 范本（解三角形 14 项）的量级吗？
- [ ] 每本教辅的单列项都进清单了吗？（对照四源目录逐条勾）
- [ ] 清单表格化了吗？（阶段4交叉验证表直接由它生成）

## 阶段 2 · 建知识体系（1 小时）

### 做什么
1. 以教材/考纲为准，把技能点对应的**全部公式/定理/定义**列全（不止教辅，教材是最全的）
2. 按"教辅知识梳理"的项数标准自查：**对照范本 02 节（11 块）**——正弦定理（含四变式）/余弦定理（含推论+判形钥匙）/面积公式（五式+高）/内角和关系/射影定理/边角关系链/正切恒等式/三角形的线（中线角平分线公式）/测量术语（表）/特殊结构/四类型总表
3. 每块标：公式内容 + 变形 + 适用场景 + 易错点

### 反模式（禁止）
- ❌ 只列"名字"不列"公式"（"三角形的线"必须有 gₐ²=¼(2b²+2c²-a²) 这种）
- ❌ 知识体系少于教辅知识梳理的项数（漏块=返工，v6 教训：测量术语/高公式/中线公式全漏过）

### 自查
- [ ] 每个技能点都有对应的公式/定义块吗？
- [ ] 对照范本 02 节，有没有范本有而你没有的块（说明漏了）？

## 阶段 3 · 建模型树（2 小时，核心产出）

### 做什么
按范本 v9 的模型树格式（分类→排除→收敛）组织：

```
[模块名]（根）
├─ M0 入口分流 → 拿到题它问什么？
├─ M1 [核心候选模型] → 候选表（N 项）→ 排除 → 收敛
├─ M2 [必经关卡]（⚠ 高失分点，画成关卡不是分支）
├─ M3...M7 下游模型（按 M0/M1 收敛结果进入）
└─ 选学模型（标"90 分后/暂不碰"）
```

### 每个模型统一格式（照范本）
```
### 模型 Mx · 名称（触发条件）
| 候选 | 适用条件 | 排除条件 |（候选表：列全→条件不满足删除）
**收敛**：条件命中的唯一候选 = 路径。执行动作：...
**易错**：...
**采分点**：...
```

### 建模纪律
1. **M1 候选表 = 阶段1 技能点全集**（不是挑几个"重要的"——全部技能点都要有归宿）
2. **关卡 ≠ 分支**：高失分点（如角的取舍）画成"必经关卡"，从候选①连红色线，不是并列分支
3. **选学标记**：难度中上/90 分后的模型（最值/各种线）标"选学·暂不碰"，但模型要存在（不能没有）
4. **模型间靠收敛结果连接**（收敛到互化→进 M3），不靠教辅的章节顺序

### 反模式（禁止）
- ❌ 用教辅"模块→节→类型"当组织骨架（那是内容骨架，不是打法——用户钦定）
- ❌ 候选表漏技能点（阶段1 穷举清单就是候选表素材）
- ❌ 概念不给动作（每个候选必须有"执行动作"，到"怎么做"粒度）

### 自查
- [ ] 阶段1 技能点全集 100% 映射进模型树了吗？（逐项对勾）
- [ ] 每个模型都是"候选表→排除→收敛→动作"格式吗？
- [ ] 关卡（M2 类）标红并连在必经路径上了吗？

## 阶段 4 · 交叉验证 + 收尾（1 小时）

### 做什么
1. **交叉验证表**（由阶段1 清单直接生成，范本 08 节格式）：技能点 | 四源各自位置 | ★/▲判定
2. **考情解码**（范本 01 节）：近 3 年真题——卷别/题号/分值表 + 结论（必考？解答题第几题？得分率？）
3. **方法技巧**（范本 04 节）：一题通一类（7 条左右，每条=一个可迁移动作）
4. **易混易错**（范本 05 节）：雷区表（# | 雷 | 后果），8 项左右
5. **分层练习**（范本 06 节）：基础层（50 分）/中档层（70-90）/培优层（90+，标不碰）+ 回捞规则
6. **课本典例锚点**（范本 07 节）：人教 A 版对应章节例题 + 各教辅题源

### 反模式（禁止）
- ❌ 考情编数字（必须来自真题检索，标来源）
- ❌ 技巧是概念不是动作（"画图第一"不是技巧，"方位角顺时针画"才是）

## 验收总闸（交付前最后一遍）

1. **先穷举后建模**：模型树候选表 ⊆ 阶段1 技能点全集，且无遗漏（回查穷举清单）
2. **资料区间**：引用全部来自四源教辅+教材+考纲+真题，无区间外来源
3. **能出题=可调用**：拿模型树跑一道真题，能走通"分类→排除→收敛→动作"算过
4. **证据与结论分文件**：技能点清单（证据）与模型树（结论）可分离
5. **回主脑校验**：全部完成后回传文件清单+交叉验证表 → 主脑验收
