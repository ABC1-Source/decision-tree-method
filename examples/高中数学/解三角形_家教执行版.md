# 解三角形 · 家教执行版模型树（v10 厚版）

> 定位：**家教窗口上课直接用**的版本——在 v9（产品版模型树）基础上，焊入教学执行层（怎么教/怎么练/怎么判/怎么回捞）。
> 与 v9 关系：v9=对外产品（薄，方法演示）；本版=执行资产（厚，每模型带教案动作+判定标准+错题处理）。
> 配套：单节模板（90 分钟）· 课前诊断卷 · 错题闭环 · 送分题保分。
> 学生画像：准高三 50/150 基础断层型；三角"上完"未验证（假会概率高）；函数可能断层；解答题第 1 问得分率 0.92 是保底盘。

## 01 家教全局（先读这个，再进模型树）

### 教学铁律（迁移自 python-tutor-discipline）
1. **先教 30 秒**：新符号/概念，先讲"是什么+机制+类比"再动笔
2. **拆到词**：每步拆到最小可理解单元（"正弦=纵坐标"），不假设她会
3. **机制优先**：讲为什么，不贴"坑"标签——坑从机制里长出来
4. **例题只用品组合**：只用已教工具+本节新工具，不夹带超纲
5. **做对才算会**：自评"懂了"不可信，当堂独立做对变式=过
6. **不赶进度**：一个知识点=机制讲透+当堂做对，质量优先

### 4 关框架（每模型通用）
预测（我先猜怎么解）→ 解释（为什么这么走）→ 迁移（换数字/换问法）→ 诊断（断在哪）

### 错题闭环（贯穿全程，第 1 节就建）
归因（知识不会/审题漏/计算错/思维卡 四选一）→ 3 天后重做（不翻答案）→ 变式验证（同考点另一题做对=真会）→ 每周日回捞

### 送分题保分（每节带 10 分钟）
单选前 5-6 题（集合/复数/向量 30 分）要求"必对"不是"会"——送分题的验收标准是 100% 拿满

## 03 模型树（教学执行版：每模型 = 候选表 + 教案动作 + 判定 + 错题处理）

> 做题总序（教给她，让她形成肌肉记忆）：**看已知 → 选定理 → 判取舍 → 写采分点**

### 模型 M0 · 入口分流（第 1 次课教，10 分钟）

**先教 30 秒**：拿到题别急着算，先问"它要我干什么"——求边？求角？求面积？判形状？像进饭店先看菜单，不看菜单就点菜=瞎点。

```
拿到一道解三角形题 → 它问什么？
├─ 求边 / 求角       → M1 选定理
├─ 求面积 / 周长     → M4 面积与周长
├─ 判断形状         → M5 判形状
├─ 求最值 / 范围     → M6（选学，90 分后）
└─ 图形 / 测量背景   → M7（选学标记，术语选填是送分）
```

**当堂判定**：给她 3 道题（求边/求角/求面积各 1），只让说"去哪个模型"，不说解法——说对=分流会了

### 模型 M1 · 选定理（核心模型，2 节课）

**先教 30 秒（选定理口诀）**："两角一边用正弦，三边夹角用余弦，边角混了一起化，求面积就找公式"——口诀背后是机制：正弦管"角的比例"，余弦管"边的平方"，看已知什么就调什么。

| 候选 | 适用条件 | 排除条件 |
|---|---|---|
| **正弦定理** | 两角一边 / 两边一对角 | 两边一夹角、三边 → 排除 |
| **余弦定理** | 两边一夹角 / 三边求第三边 | 两角一边 → 排除 |
| **余弦变型**（朱昊鲲 4.3 单列） | 三边求角 / 求 cos 值 | 不含三边 → 排除 |
| **比例问题**（朱昊鲲 4.4 单列） | 给 sinA:sinB:sinC 或 a:b:c | 无数值比例 → 排除 |
| **边角互化** | 式子边角混合（含 cos 式） | 纯边或纯角 → 排除 |
| **面积联立** | 求面积 | 不求面积 → 排除 |
| **外接圆半径 R**（学科网方法技巧） | 求 R / 出现 2R | 不涉及 R → 排除 |

**收敛动作（教给她三步）**：
1. 圈出已知条件（数字+限定词）
2. 对照候选表：条件满足哪个 → 走哪条
3. 不满足的全排除 → 剩下唯一 → 动手

**当堂判定**：4 道变式（正弦/余弦/变型/比例各 1）独立做对 = 过；错题归因进错题本

**教案动作（第 1-2 课用）**：
- 例题①（正弦）：两角一边求边——先教 30 秒"内角和求第三角"→ 拆到词"正弦定理=边和它对角的正弦成比例"→ 代入 → 采分点
- 例题②（余弦）：三边求角——先教 30 秒"余弦定理推论=三边求角的钥匙"→ 拆到词"分子=另两边平方和-对边平方"→ 代入
- 例题③（比例）：sinA:sinB:sinC=3:5:7 求角——先教 30 秒"比例设 k"→ 拆到词"a=3k,b=5k,c=7k"→ 余弦定理求角

### 模型 M2 · 角的取舍（⚠ 必经关卡，单独 1 节课）

**先教 30 秒**：用正弦求角，算出来 sinB=½——B 是 30° 还是 150°？**不能两个都写，也不能只写一个**——要判解数。这是 50 分学生丢分最集中的地方（一数单列成节验证）。

```
A 为锐角时（已知 a、b、A 求 B）：
  a < b·sinA → 无解
  a = b·sinA → 一解（直角）
  b·sinA < a < b → 两解（一锐一钝）
  a ≥ b → 一解
A 为钝角/直角时：
  a ≤ b → 无解
  a > b → 一解
```

**辅助判据**：大边对大角——算出的角若大于已知大边对角，舍

**当堂判定**：3 道判解题（两解/一解/无解各 1）——**要求写出判断过程**，不只是答案（判解本身给分）

**教案动作**：
- 先教 30 秒"大边对大角"：边长越大，对角越大——像门板越大，门框角度越大
- 拆到词：b·sinA 是什么？A 角的对边高——比高矮就知道有几个解
- 采分点示范："∵a=3, b=4, A=30°，b·sinA=2，a>b·sinA 且 a<b ∴两解"——这句就是分数

### 模型 M3 · 边角互化（中档，70-90 分目标）

| 候选 | 目标 | 动作 |
|---|---|---|
| **化角类** | 求角 | 边→角（a=2R·sinA）→ 恒等化简 → 得角 |
| **化边类** | 求边/比值 | 角→边（sinA=a/2R）→ 代数化简 → 得边关系 |
| **综合恒等** | 混合 | 三大统一（角度/名称/次数）→ 再互化 |

**判定**：求角就化角，求边就化边，求面积边角结合
**当堂判定**：2 道变式（化角 1/化边 1）做对 = 过
**易错**：化角漏 2R；互化后忘用内角和消元；cos(A+B)=**-cosC**（负号！）

### 模型 M4 · 面积与周长（解答题第 2 问常态）

| 候选 | 已知 | 动作 |
|---|---|---|
| ½ab·sinC | 两边一夹角 | 直接代（最常用） |
| ½·a·hₐ | 底和高 | 直接代 |
| abc/4R | 外接圆半径 | 代 |
| **面积+余弦联立** | 面积+边角关系（解答题第 2 问） | 联立消元求边/角 |
| **周长**（学科网题型6 单列） | 求 a+b+c | 边角互化消元 → 化单变量 → 求值/范围 |

**当堂判定**：面积+余弦联立 1 道做对 = 过
**易错**：面积公式选错；算完忘验三角形存在；周长题没先定"消哪个变量"

### 模型 M5 · 判形状（中档）

| 候选 | 动作 |
|---|---|
| **化边判形** | 边角互化 → 看 a²、b²、c² 关系（勾股判形钥匙） |
| **化角判形** | 边角互化 → 三角恒等 → 得角关系 |

**⚠ 红线（必教）**：公因式禁止直接约（移项提取，约掉=漏一种形状）
**特殊陷阱**：sin2A=sin2B ⇔ A=B 或 A+B=π/2
**当堂判定**：2 道判形题做对 = 过

### 模型 M6 · 最值/范围（选学，90 分后，家教不主动上）

标记"暂不碰"——50 分学生的时间花在 M0-M2 上，最值是 90 分以后的题

### 模型 M7 · 几何图形·实际应用（选学标记，术语选填送分）

| 候选 | 特征 | 动作 |
|---|---|---|
| 射影定理 | 式子含 b·cosC+c·cosB 型 | 直接套，化简极快 |
| 多边形（有确定三角形） | 某三角形三元素已知 | 先解确定三角形 → 链式推相邻 |
| 多边形（无确定三角形） | 无三元素齐全 | 设未知数 → 每三角形列方程 → 联立 |
| 各种线 | 中线/角分线/高 | gₐ²=¼(2b²+2c²-a²)；iₐ=2bc·cos(A/2)/(b+c) |
| 距离/高度/角度测量 | 仰俯角/方位角/坡比 | 画图（⚠ 方位角顺时针）→ 找确定三角形 |

**术语选填是送分**：M7 的术语辨析（仰俯角/方位角/方向角/坡比）50 分就该会——每节课带 1 道概念题

## 04 送分题保分训练（每节课前 10 分钟）

1. 单选前 5-6 题专项：集合/复数/向量/不等式/函数定义域
2. 要求：**必对**（不是"会"）——错一题就是保底盘漏一分
3. 方式：限时 3 分钟/题 → 圈条件 → 对答案 → 错题进本子

---

## 05 单节模板（90 分钟，教学执行用）

```
0-10 分钟  错题回捞（上次错题重做，5 题内）
10-20 分钟 送分题保分（3 题限时）
20-50 分钟 新知识（先教 30 秒 → 拆到词 → 例题 ×2-3）
50-70 分钟 当堂练习（学生独立做，现场纠——"听懂了不会做"是 50 分学生最大问题）
70-85 分钟 变式验证（A 组做对才给 B 组变式，做对才算会）
85-90 分钟 布置作业（5-8 题精做）+ 错题本归因
```

**判定标准**：当堂独立做对变式题 = 过；错了回炉对应模型，不上新课

## 07 课前准备清单（每课前一天）

1. 断点地图检查：她上节课断在哪 → 本课回捞题选什么
2. 例题过一遍（先教 30 秒的话术想好，类比想好——钟表盘/门板/菜谱）
3. 变式题准备好（A 组 3 道 + B 组 2 道，只用已教工具）
4. 送分题 3 道（集合/复数/向量轮换）
5. 错题本带齐（学生自己带，第 1 节就建好）
