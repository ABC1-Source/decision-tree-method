## 02 知识体系（模型树的原料库，先背后走）

### 一、正弦定理
a/sinA = b/sinB = c/sinC = 2R（R=外接圆半径）
**四变式**：① a=2R·sinA（边→角）② sinA=a/2R（角→边）③ a:b:c = sinA:sinB:sinC ④ a·sinB = b·sinA（交叉相等）

### 二、余弦定理
a²=b²+c²-2bc·cosA（轮换 b²、c²）
推论：cosA=(b²+c²-a²)/2bc
**判形钥匙**：a²=b²+c²⇔直角；a²>b²+c²⇔钝角；a²<b²+c²⇔锐角

### 三、面积公式（五式 + 高）
① S=½·a·hₐ ② S=½ab·sinC（最常用）③ S=abc/4R ④ S=½r(a+b+c) ⑤ 海伦（选学）
**高公式**：hₐ=b·sinC=c·sinB（求高直接套，不用先算面积）

### 四、内角和关系
A+B+C=π；sin(A+B)=sinC；**cos(A+B)=-cosC**；tan(A+B)=-tanC；sin[(A+B)/2]=cos(C/2)

### 五、射影定理
a=b·cosC+c·cosB；b=a·cosC+c·cosA；c=a·cosB+b·cosA

### 六、边角关系链
A>B ⇔ a>b ⇔ sinA>sinB ⇔ cosA<cosB

### 七、正切恒等式
tanA+tanB+tanC = tanA·tanB·tanC

### 八、三角形的线
- **中线长**：gₐ²=¼(2b²+2c²-a²)
- **角平分线长**：iₐ=2bc·cos(A/2)/(b+c)；角平分线定理 BD/DC=AB/AC

### 九、测量术语
| 术语 | 定义 | 关键点 |
|---|---|---|
| 仰角/俯角 | 目标视线与水平视线的夹角 | 同一铅垂平面内 |
| 方位角 | 指北方向线**顺时针**到目标线夹角 | 0°≤θ<360° |
| 方向角 | 如"北偏东α" | 方位角的表达形式 |
| 坡角/坡比 | 坡面与水平面锐角 θ；i=h/l=tanθ | 垂直高:水平长 |

### 十、特殊结构
A、B、C 成等差 ⇔ B=60°；正三角形 ⇔ 三角等差且三边等比

### 十一、解三角形四类型（选定理的输入总表）
| 已知 | 用 | 解数 |
|---|---|---|
| 两角一边 | 正弦 | 一解 |
| 两边一对角 | 正弦 | ⚠ 判解表（见 M2） |
| 两边一夹角 | 余弦 | 一解 |
| 三边 | 余弦 | 一解 |

## 03 模型树（分类→排除→收敛 · 全模块统一格式）

> 做题总序：**看到题 → 分类（识别候选）→ 排除（条件不满足删）→ 收敛唯一 → 执行**。
> 每个模型 = 候选表（适用条件）→ 排除 → 收敛 → 动作。模型间靠"必经关卡"串成树。

```
解三角形（根）
├─ M0 入口分流 → 求什么？
├─ M1 选定理 → 候选：正弦/余弦/余弦变型/比例/互化/面积联立/外接圆 → 排除 → 收敛
├─ M2 角的取舍（⚠ 用正弦求角的必经关卡）
├─ M3 边角互化（M1 收敛到"互化"时进入）
├─ M4 面积与周长（M0 收敛到"求面积/周长"时进入）
├─ M5 判形状
├─ M6 最值/范围（选学，90 分后）
└─ M7 几何图形·实际应用（选学标记）
```

### 模型 M0 · 入口分流（分类第一步）

```
拿到一道解三角形题 → 它问什么？
├─ 求边 / 求角       → M1 选定理
├─ 求面积 / 周长     → M4 面积与周长
├─ 判断形状         → M5 判形状
├─ 求最值 / 范围     → M6（选学，90 分后）
└─ 图形 / 测量背景   → M7（选学标记，术语选填是送分）
```

### 模型 M1 · 选定理（候选→排除→收敛 · 全候选表）

| 候选 | 适用条件 | 排除条件 |
|---|---|---|
| **正弦定理** | 两角一边 / 两边一对角 | 两边一夹角、三边 → 排除 |
| **余弦定理** | 两边一夹角 / 三边求第三边 | 两角一边 → 排除 |
| **余弦变型**（朱昊鲲 4.3 单列） | 三边求角 / 求 cos 值 | 不含三边 → 排除 |
| **比例问题**（朱昊鲲 4.4 单列） | 给 sinA:sinB:sinC 或 a:b:c | 无数值比例 → 排除 |
| **边角互化** | 式子边角混合（含 cos 式） | 纯边或纯角 → 排除 |
| **面积联立** | 求面积 | 不求面积 → 排除 |
| **外接圆半径 R**（学科网方法技巧） | 求 R / 出现 2R | 不涉及 R → 排除 |

**收敛**：条件命中的唯一候选 = 路径。执行动作：
- 收敛到正弦 → 内角和求第三角 → 正弦定理 → **必过 M2**
- 收敛到余弦 → 直接代入 → 注意"对边平方"位置
- 收敛到余弦变型 → cosA=(b²+c²-a²)/2bc 直接代（分子=另两边平方和-对边平方）
- 收敛到比例 → **设 k**：a:b:c=sinA:sinB:sinC → 全用 k 表示代入
- 收敛到互化 → 进 M3
- 收敛到面积 → 进 M4
- 收敛到外接圆 → R=a/2sinA（正弦定理变形）

**易错**：不写"由正弦定理得/余弦定理得"直接代 = 扣 30%；求角时 a² 是"对边"的平方；比例题忘了设 k

### 模型 M2 · 角的取舍（⚠ 用正弦求角的必经关卡，一数单列验证）

> 凡正弦求角（sinB=½ 这种），先过判解表：

```
A 为锐角时（已知 a、b、A 求 B）：
  a < b·sinA → 无解
  a = b·sinA → 一解（直角）
  b·sinA < a < b → 两解（一锐一钝）
  a ≥ b → 一解
A 为钝角/直角时：
  a ≤ b → 无解
  a > b → 一解
```

- 辅助判据：**大边对大角**（算出的角若大于已知大边对角，舍）
- 特殊陷阱：sin2A=sin2B ⇔ A=B **或 A+B=π/2**
- 采分点：先写"∵…∴两解"——**判解本身给分**

### 模型 M3 · 边角互化（M1 收敛到"互化"时进入）

| 候选 | 目标 | 动作 |
|---|---|---|
| **化角类** | 求角 | 边→角（a=2R·sinA）→ 恒等化简 → 得角 |
| **化边类** | 求边/比值 | 角→边（sinA=a/2R）→ 代数化简 → 得边关系 |
| **综合恒等** | 混合 | 三大统一（角度/名称/次数）→ 再互化 |

- 判定：**求角就化角，求边就化边，求面积边角结合**
- 易错：化角漏 2R；互化后忘用内角和消元；sin(A+B)→sinC、cos(A+B)→**-cosC**

### 模型 M4 · 面积与周长（M0 收敛到"求面积/周长"时进入）

| 候选 | 已知 | 动作 |
|---|---|---|
| ½ab·sinC | 两边一夹角 | 直接代（最常用） |
| ½·a·hₐ | 底和高 | 直接代 |
| abc/4R | 外接圆半径 | 代 |
| **面积+余弦联立** | 面积 + 边角关系（解答题第 2 问常态） | 联立消元求边/角 |
| **周长**（学科网题型6 单列） | 求 a+b+c | 边角互化消元 → 化单角/单变量 → 求值或范围 |

- 高公式：hₐ=b·sinC=c·sinB（求高直接套）
- 易错：面积公式选错；算完忘验三角形存在；周长题没先定"消哪个变量"就动手

### 模型 M5 · 判形状

| 候选 | 动作 |
|---|---|
| **化边判形** | 边角互化 → 看 a²、b²、c² 关系（勾股判形钥匙） |
| **化角判形** | 边角互化 → 三角恒等 → 得角关系 |

- ⚠ 红线：**公因式禁止直接约**（移项提取，约掉=漏一种形状）
- 特殊陷阱：sin2A=sin2B ⇔ A=B 或 A+B=π/2

### 模型 M6 · 最值/范围（选学，90 分后）

| 候选 | 适用 | 动作 |
|---|---|---|
| 基本不等式法 | 和定/积定结构 | 余弦定理+基本不等式（注意取等条件） |
| 三角函数法 | 能化单角 | 边化角 → Asin(ωx+φ) → 值域（⚠ 先定角范围） |
| 切弦互化 | 含 tan 条件 | 切化弦 → 边角互化 → 按上两候选 |

- 标记：50 分学生**不碰**

### 模型 M7 · 几何图形·实际应用（选学标记，术语选填是送分）

| 候选 | 特征 | 动作 |
|---|---|---|
| 射影定理 | 式子含 b·cosC+c·cosB 型 | 直接套，化简极快 |
| 多边形（有确定三角形） | 图中某三角形三元素已知 | 先解确定三角形 → 链式推相邻 |
| 多边形（无确定三角形） | 无任何三角形三元素齐全 | 设未知数 → 每三角形列方程 → 联立 |
| 各种线（中线/角分线/高） | 问中线/角平分线 | 公式：gₐ²=¼(2b²+2c²-a²)；iₐ=2bc·cos(A/2)/(b+c)；角平分线定理 |
| 距离/高度/角度测量 | 仰俯角/方位角/坡比 | 画图（⚠ 方位角顺时针）→ 找确定三角形 → 解 |

## 04 方法技巧（一题通一类）

1. **选定理三问**：已知啥？目标啥（求角化角、求边化边、求面积边角结合）？要不要判取舍（正弦求角必判）？
2. **角的取舍三件套**：判解表 → 大边对大角 → 舍解写理由
3. **边角互化看目标**：式子含什么就往什么方向化，化完能用内角和/恒等变形消元
4. **几何题找确定三角形**：三元素已知的那个先解，它是全图的钥匙
5. **三大统一**：角度 → 名称 → 次数，变一次看一次是否在收敛
6. **比例题设 k**：见 sinA:sinB:sinC 或 a:b:c → 设比例系数 k 全代（朱昊鲲 4.4）
7. **应用题画图第一**：方位角顺时针、仰俯角标图，图错=整题错；术语辨析选填是送分
