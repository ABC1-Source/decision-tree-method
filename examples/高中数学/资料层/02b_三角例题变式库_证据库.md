## 变式设计三级（全库统一）

| 级 | 名称 | 目的 |
|---|---|---|
| ① | **换数** | 同结构换数字。验证她掌握的是流程不是这一道题的答案 |
| ② | **逆问** | 把已知和所求调头。验证她理解的是关系不是单向套路 |
| ③ | **设陷阱** | 埋一个机制漏洞（无解 / 轴线角 / 漏象限 / 符号）。验证她有机制而不是有印象 |

**工具标注约定**：每题标 `[工具: …]`，只允许出现「初中已有（坐标/勾股/锐角三角比/特殊角值）」+「已教模块 M1…Mn」。
超出即违反"例题只用品组合"，**发现请驳回**。

难度标：★ 定义级（必须对）｜★★ 一步应用｜★★★ 两步或含讨论

# 第 1 课题库

## M1 任意角

**母题 1**｜写出与 30° 终边相同的角的集合。 ★ `[工具: M1]`
**答**：{β | β = 30° + k·360°, k ∈ Z}

- ① 换数：与 −45° 终边相同的角的集合。**答**：{β | β = −45° + k·360°, k ∈ Z}
- ① 换数：与 120° 终边相同的角的集合。**答**：{β | β = 120° + k·360°, k ∈ Z}
- ② 逆问：在集合 {β | β = 30° + k·360°} 中，取 k = −1，这个角是多少？ **答**：−330°
- ② 逆问：在 0°~360° 范围内，写出与 −120° 终边相同的角。 ★★ **答**：240°
- ③ 陷阱：判断 30°、390°、−330°、750° 四个角终边是否都相同。 ★★ **答**：都相同（依次差 360°、−720°、720°）

**母题 2**｜判断 −60° 是第几象限角。 ★ `[工具: M1]` **答**：第四象限

- ① 换数：750° 是第几象限角？ ★★ **答**：750° − 720° = 30° → 第一象限
- ① 换数：−200° 是第几象限角？ ★★ **答**：−200° + 360° = 160° → 第二象限
- ③ 陷阱：90° 是第几象限角？ ★★ **答**：**不属于任何象限**（终边在 y 轴正半轴上，是轴线角）。
  → 这题错了不算粗心，说明"象限角"的定义没立住，回 M1 拆词

**现场出题模板（M1）**
> 「判断 ____ 是第几象限角」——填入任意 |θ| > 360° 或 θ < 0 的角，逼她做整圈加减。
> 「写出与 ____ 终边相同的角的集合」——填入任意角，检查她是否漏 `k∈Z`。
> 陷阱位固定用 0°、90°、180°、270° 这四个轴线角。

## M2 弧度制

**母题 3**｜把 150° 化为弧度。 ★ `[工具: M2]` **答**：150 × π/180 = **5π/6**

- ① 换数：210° → **7π/6**；315° → **7π/4**；22.5° → **π/8**
- ② 逆问（母题 4）：把 2π/3 化为度。**答**：**120°**
- ② 逆问续：5π/4 → **225°**；3π → **540°**；π/12 → **15°**
- ③ 陷阱：比较 `sin 2` 与 `sin 2°` 是不是同一个数。 ★★
  **答**：不是。`sin 2` 是 2 弧度（≈114.6°）的正弦，`sin 2°` 是 2 度的正弦。**弧度制下不写单位，漏写度数符号就换了一道题。**

**母题 5**｜半径 3、圆心角 π/4 的扇形，弧长是多少？ ★★ `[工具: M2]` **答**：l = αr = (π/4)·3 = **3π/4**

- ① 换数：半径 2、圆心角 π/3 → **2π/3**
- ② 逆问：半径 2、弧长 π，圆心角是多少弧度？ **答**：α = l/r = **π/2**
- ② 逆问：弧长 6、圆心角 2 弧度，半径是多少？ **答**：r = l/α = **3**

**附加（可选，时间紧则顺延）**：扇形面积 `S = ½ l r`
> 机制（先教 30 秒）：扇形是圆的一部分，**它占圆的比例，等于弧长占周长的比例**。
> S / (πr²) = l / (2πr) → S = ½ l r。不是新公式，是一个比例。
- 例：半径 3、圆心角 π/4 → l = 3π/4 → S = ½ · (3π/4) · 3 = **9π/8**

**现场出题模板（M2）**
> 「____° 化为弧度」/「____ 化为度」——两边各出一道，必须双向。
> 「半径 __、圆心角 __，求弧长」→ 换成「已知弧长求半径」就是逆问。
> 陷阱位固定考"漏度数符号"和"弧度带单位"。

## M3 单位圆与定义

**母题 6**｜α 的终边与单位圆交于 P(−3/5, 4/5)，求 sin α、cos α、tan α。 ★ `[工具: 坐标, M3]`
**答**：sin α = **4/5**，cos α = **−3/5**，tan α = (4/5)/(−3/5) = **−4/3**

- ① 换数：P(5/13, −12/13) → sin = **−12/13**，cos = **5/13**，tan = **−12/5**
- ① 换数：P(√2/2, √2/2) → sin = cos = **√2/2**，tan = **1**（此时 α = π/4）
- ② 逆问：已知 cos α = −1，α 的终边穿过单位圆上哪一点？ ★★ **答**：(−1, 0)，即 α = π（或 π + 2kπ）
- ③ 陷阱（**需先教 30 秒**）：点 P(3, 4) 在角 α 的终边上（**注意：不在单位圆上**），求 sin α。 ★★★
  > 30 秒机制：不在单位圆上时，把这个点沿着终边缩放到单位圆上——**方向没变，比值不变**（相似三角形）。所以 sin α = y / r，其中 r = √(x²+y²)。
  **答**：r = √(9+16) = 5 → sin α = **4/5**
  → 这一型高考常用（给一般点而不给单位圆上的点），但**必须先讲机制再给题**，否则是跳步

**母题 7**｜直接读出 sin(π/2)、cos π、tan 0。 ★ `[工具: M2, M3]`
**答**：先说出终边穿过的点：(0,1)、(−1,0)、(1,0) → **1**、**−1**、**0**

- ① 换数：cos(π/2) = **0**；sin π = **0**；sin(3π/2) = **−1**；cos(2π) = **1**；tan π = **0**
- ③ 陷阱：求 tan(π/2)。 ★★ **答**：**不存在**（终边上的点横坐标 x = 0，y/x 分母为 0）。不是 0，也不是无穷大这种含糊说法——是没有定义

**母题 8**｜判断对错："sin α 一定小于 1。" ★★ `[工具: M3]`
**答**：**错**。α = π/2 时 sin α = 1。正确说法是 **|sin α| ≤ 1**（纵坐标走不出单位圆）

**现场出题模板（M3）**
> 「终边与单位圆交于 P(__, __)，求三个值」——任取一组满足 x²+y² = 1 的数（勾股数 /5、/13、/25 最方便）。
> 「直接读出 sin/cos/tan(轴线角)」——从 0、π/2、π、3π/2、2π 里任取。
> 陷阱位：tan(π/2) 不存在；给不在单位圆上的点。

## M4 象限符号

**母题 9**｜判断符号：sin 200°、cos(2π/3)、tan(−π/4)。 ★ `[工具: M1, M2, M4]`
**答**：sin 200°（第三象限，y<0）→ **负**；cos(2π/3)（=120°，第二象限，x<0）→ **负**；tan(−π/4)（第四象限，y<0 且 x>0）→ **负**
**验收要求**：必须口述"终边在第几象限 → 那里 x、y 什么符号 → 所以…"

- ① 换数：sin(−π/3) → **负**；cos 300° → **正**；tan 120° → **负**；sin(5π/6) → **正**
- ② 逆问：若 sin α > 0 且 cos α < 0，α 是第几象限角？ ★★ **答**：**第二象限**
- ② 逆问：若 tan α > 0，α 可能在第几象限？ ★★ **答**：**第一或第三**（y/x 同号即可）
- ③ 陷阱：若 sin α = 0，α 在第几象限？ ★★ **答**：**不在任何象限**（终边落在 x 轴上）

**现场出题模板（M4）**
> 「判断 ___ 的符号」——把角随机丢进四个象限，三个函数轮流问。
> 逆问模板：「已知两个函数的符号，定象限」/「已知一个函数符号，问可能的象限」。

## M5 同角关系

**母题 10**｜已知 sin α = 3/5，α 是第二象限角，求 cos α、tan α。 ★★ `[工具: M4, M5]`
**答**：sin²+cos² = 1 → cos²α = 1 − 9/25 = 16/25 → cos α = ±4/5；第二象限 x<0 → **cos α = −4/5**；tan α = (3/5)/(−4/5) = **−3/4**
**验收要求**：必须走完"算大小 → 定符号"两步。只写到 ±4/5 = 未过

- ① 换数：cos α = −4/5，α 在第三象限 → sin α = **−3/5**，tan α = **3/4**
- ① 换数：sin α = −5/13，α 在第四象限 → cos α = **12/13**，tan α = **−5/12**
- ② 逆问：已知 cos α = 4/5 且 sin α < 0，求 sin α 并指出 α 在第几象限。 ★★ **答**：sin α = **−3/5**，**第四象限**
- ③ 陷阱：已知 sin α = 1/2 且 α 是第三象限角，求 cos α。 ★★★
  **答**：**无解 / 条件矛盾**。第三象限 y < 0，sin α 不可能等于 1/2。
  → 这题的价值：检验她是"套公式"还是"看着单位圆想"。套公式的人会算出 −√3/2 并交卷
- ③ 陷阱：判断对错"sin²α + cos²β = 1"。 ★★ **答**：**错**，必须是**同一个角**。同角关系的"同"字是条件不是修饰

**母题 11**｜判断对错："已知 sin α = 3/5，则 cos α = 4/5。" ★★
**答**：**错**。没给象限，cos α = ±4/5 两种都可能

**现场出题模板（M5）**
> 「已知 sin/cos = ±(勾股数比)，α 在第 __ 象限，求另两个」——勾股数用 3-4-5、5-12-13、8-15-17。
> 陷阱位两个固定款：**给矛盾象限**（无解）、**不给象限**（漏 ±）。

# 第 2 课题库

## M6 诱导公式

**母题 12**｜求 sin(7π/6)。 ★★ `[工具: M2, M5, M6]`
**答**：7π/6 = π + π/6 → 原点对称 → sin(π+α) = −sin α → **−1/2**
**验收要求**：先画单位圆、指出对称点，再写符号

- ① 换数：cos(4π/3) = cos(π+π/3) = **−1/2**
- ① 换数：sin(5π/6) = sin(π−π/6) = **1/2**（y 轴对称，sin 不变号）
- ① 换数：cos(−π/3) = **1/2**（x 轴对称，cos 不变号）；sin(−π/4) = **−√2/2**
- ① 换数：sin(5π/3) = sin(2π−π/3) = **−√3/2**；cos(11π/6) = **√3/2**
- ② 逆问：在 [0, 2π] 内，哪些角的正弦值等于 1/2？ ★★★ **答**：**π/6 和 5π/6**（一个在第一象限，一个是它的 y 轴对称点）
- ③ 陷阱（超整圈）：sin(13π/6)。 ★★ **答**：13π/6 = 2π + π/6 → 转整圈值不变 → **1/2**
- ③ 陷阱（度数混入）：cos(−420°)。 ★★ **答**：cos(420°) = cos(60°) = **1/2**

**现场出题模板（M6）**
> 取一个特殊角 β ∈ {π/6, π/4, π/3}，再随机套一个外壳：`−β`、`π−β`、`π+β`、`2π−β`、`2kπ+β`。
> 5 种外壳 × 3 个特殊角 × 2 个函数 = 30 道同型题，随时可生成。
> **注意：不要出 π/2 ± β 型**（本课未讲，超纲二分已裁定顺延）。

## M7 图像

**母题 13**｜用五点法画 y = sin x 在 [0, 2π] 上的图像。 ★ `[工具: M2, M3, M7]`
**答**：五点 (0,0)、(π/2,1)、(π,0)、(3π/2,−1)、(2π,0)，连成一升一降的波

- ① 换数：用五点法画 y = cos x 在 [0, 2π] 上的图像。**答**：(0,1)、(π/2,0)、(π,−1)、(3π/2,0)、(2π,1)。差别：**余弦从最高点起步，正弦从 0 起步**
- ② 逆问（读图）：在你画的正弦图上，标出 y = 1/2 出现的两个位置。 ★★ **答**：x = π/6 与 x = 5π/6（与 M6 逆问互为印证）
- ② 逆问（读图）：在正弦图上指出 y 取最大值的位置。 ★ **答**：x = π/2（一般地 x = π/2 + 2kπ）
- ③ 陷阱：比较 sin 1 与 sin 2 的大小（1、2 均为弧度）。 ★★★ **选做**
  **答**：sin 2 = sin(π − 2) = sin(1.14…)，而 1.14 > 1，两者都在 [0, π/2] 的递增段上 → **sin 2 > sin 1**

**现场出题模板（M7）**
> 「画 y = sin x / cos x 在 [__, __] 上的图像」——区间可换 [−π, π]、[0, 4π]。
> 读图型：「标出 y = __ 的位置」「指出最大 / 最小 / 零点位置」。

## M8 性质

**母题 14**｜写出 y = sin x 的最小正周期和值域。 ★ `[工具: M7, M8]` **答**：**2π**；**[−1, 1]**

- ① 换数：y = cos x 的最小正周期和值域。**答**：**2π**；**[−1, 1]**
- ② 逆问：判断 y = cos x 的奇偶性，并说出你是怎么看出来的。 ★★
  **答**：**偶函数**。理由二选一：图像关于 y 轴对称 / cos(−α) = cos α（M6 的 x 轴对称）
  **验收要求**：只答"偶函数"不算过，必须给出理由
- ② 逆问（读图）：写出 y = sin x 在 [0, 2π] 内的一个递减区间。 ★★ **答**：**[π/2, 3π/2]**
- ② 逆问：写出 y = sin x 的对称轴。 ★★★ **答**：**x = π/2 + kπ, k∈Z**
- ③ 陷阱：y = sin x + 1 的值域是什么？ ★★
  **答**：**[0, 2]**（整条曲线抬高 1 格）。陷阱在于有人会答 [−1, 1] 不变，或答 [1, 2]
- ③ 陷阱：判断"y = sin x 在 (0, 2π) 上是增函数"。 ★★ **答**：**错**，先增后减，不能整段说增

**现场出题模板（M8）**
> 五个性质各配一问：周期 / 值域 / 奇偶 / 单调区间 / 对称。
> 陷阱位固定两款：**整段说单调**、**上下平移后忘记改值域**。

## M9 y = A sin(ωx + φ) 第一层（**仅在 M6–M8 全过后使用**）

**母题 15**｜y = 3sin(2x + π/3)，求振幅、最小正周期、最大值、最小值。 ★★ `[工具: M8, M9]`
**答**：A = **3**；T = 2π/ω = 2π/2 = **π**；最大 **3**；最小 **−3**

- ① 换数：y = 2sin(x/2 − π/4) → A = **2**，T = 2π/(1/2) = **4π**，最大 **2**，最小 **−2**
- ③ 陷阱：y = −sin(3x) → A = **1**（振幅是"波多高"，取绝对值，负号只是把波上下翻），T = **2π/3**，最大 **1**，最小 **−1**

**现场出题模板（M9）**
> 「y = A sin(ωx + φ)，求 A、T、最值」——A 随机取含负数，ω 随机取含分数。
> **不要出**"已知图像求 φ"（超纲二分已裁定顺延）。

## 第 2 课 · 当堂练习（20 分钟，6 题）

1. 求 sin(2π/3)、cos(7π/6)。 ★★
2. 求 sin(−5π/6)、cos(−π/6)。 ★★
3. 用五点法画 y = sin x 在 [0, 2π] 上的图像，并标出 y = −1 的位置。 ★
4. 写出 y = cos x 的最小正周期、值域、奇偶性（奇偶性要给理由）。 ★★
5. 在 [0, 2π] 内找出所有满足 sin x = √3/2 的 x。 ★★★
6. y = 4sin(2x) 的振幅、周期、最大值。 ★★

**答**：1. sin(2π/3) = sin(π−π/3) = √3/2；cos(7π/6) = cos(π+π/6) = −√3/2
2. sin(−5π/6) = −sin(5π/6) = −1/2；cos(−π/6) = √3/2
3. 五点如母题 13；y = −1 在 x = 3π/2
4. 2π；[−1,1]；偶函数（图像关于 y 轴对称 / cos(−x)=cos x）

## 第 2 课 · 作业（6 题）

1. 求 sin(4π/3)、cos(5π/6)、sin(−π/3)。 ★★

6. 判断对错并说理由：(a) cos(π + α) = cos α；(b) sin x 的最大值是 1，所以 sin x = 2 有解。 ★★
