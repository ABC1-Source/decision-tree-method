## 一、通用决策树格式（每个模块都按这个骨架教）

**原则：例题给「看到什么走哪条路」，不给知识堆。**

一道题进课堂，走四步：

```
① 题型 ── 看到什么信号，判定它属于哪一类
        （例：看到「求 f(a)」→ 这是「对应关系」类，不是「求值」类）
② 分类 ── 这一型有哪些分支，各自的前提是什么
        （例：解含参不等式 → 二次项系数是否定号？是否要讨论？）
③ 排除 ── 每个分支的易错/陷阱，先把它排除了
        （例：x²−4≥0 → 排除「只写 x≥2」，必须两边；排除「方向反」）
④ 收敛 ── 收敛到唯一解法路径，学生照走
        （例：→ 因式分解 → 零点 → 穿针 → 写解集）
```

**课堂话术模板（讲例题时必说）**：
- 「这题第一眼看到 ___，所以它归到 ___ 类。」
- 「这类有两种走法：___ 和 ___。区别在 ___。」
- 「容易错在 ___，我们先把它排除掉。」
- 「所以走 ___ 这条路：第一步 ___，第二步 ___。」

**验收（对应 G5 看机制不看答案）**：学生能独立说出「看到 X → 走 Y 路」= 过；只写出答案说不出路径 = 未过。

## 二、三角决策树实例（5 板块 · 10 考点）

> 对应 02 讲义 M1–M9。结构：板块 → 考点 → 题型入口 → 分类分支 → 排除(易错) → 收敛路径
> 用途：第 1-2 课按此树授课；诊断卷 T 区（v3.1）验证真会/假会/真空后，假会板块回补、真会跳过

### 板块 1 · 概念奠基
**考点① 任意角（正/负/象限角/轴线角）**
- 题型入口：给一个角（可超 360° 或为负），问「第几象限角 / 轴线角」
- 分类：正角(逆) / 负角(顺) / 零角；终边在轴 → 轴线角（**不属于任何象限**）
- 排除：把 90°/180° 等算成「第一象限角」——轴线角无象限
- 收敛：画始边(+x)→转→看终边落点

**考点② 弧度制（换算 / 无单位机制）**
- 题型入口：度↔弧度互化；或「为什么 sin 2 没单位」
- 分类：特殊值(π/6,π/4,π/3,π/2)直接背；一般值用 π=180° 支点推
- 排除：写 `sin 2°` 当 `sin 2`（漏度数符号=另一题）；以为弧度带单位
- 收敛：π 弧度=180° → 1°=π/180 → 乘/除

**考点③ 终边相同的角（集合 k∈Z）**
- 题型入口：写「与 α 终边相同的角的集合」
- 分类：β = α + k·360°(k∈Z)
- 排除：漏写 `k∈Z`（=说「只有一个角」，错）；k 只取正数
- 收敛：集合表示，且能说清 k 是「任意圈数」

### 板块 2 · 函数定义
**考点④ 单位圆定义（坐标 / 半径）**
- 题型入口：给终边过点 P(x,y)（未必在单位圆），求 sin/cos/tan
- 分类：单位圆上 → 直接读坐标；一般圆 → 先算 r=√(x²+y²)，再 sin=y/r, cos=x/r
- 排除：把 P 当单位圆点直接读（r≠1 时错）；tan 在 x=0 时「无意义」当「0」
- 收敛：r → 三比值

**考点⑤ 同角关系（sin²+cos²=1，tan=sin/cos）**
- 题型入口：已知 sin 求 cos；或证等式
- 分类：平方关系定**大小** → 象限定**符号**（两步不可省）
- 排除：「已知 sin=3/5 则 cos=4/5」（漏符号，错）；把 sin²α 写成 sin(α²)
- 收敛：大小(平方关系) → 符号(象限) → 组合

### 板块 3 · 符号与诱导
**考点⑥ 象限符号（推不背）**
- 题型入口：判断 sin/cos/tan 在某角的符号
- 分类：按终边所在象限，问 x、y 符号
- 排除：靠背口诀答对（不算过，G5）；符号与坐标脱节
- 收敛：想坐标 → x 定 cos、y 定 sin、y/x 定 tan

**考点⑦ 诱导公式（三种对称）**
- 题型入口：求 sin(π+α) / cos(−α) / sin(π−α) 等
- 分类：−α(x轴对称) / π−α(y轴对称) / π+α(原点对称) / 2kπ+α(不变)
- 排除：背 8 组公式（应是对称推）；π/2±α 横纵互换（本课不讲，留后续）
- 收敛：画单位圆 → 指对称点 → 换号

### 板块 4 · 图像
**考点⑧ 五点法（画 y=sin x / cos x）**
- 题型入口：画 [0,2π] 图像；或「指出某值出现位置」
- 分类：取 0, π/2, π, 3π/2, 2π 五骨架点
- 排除：连线方向错（起落反）；cos 当「形状不同」（只是起点不同）
- 收敛：纵坐标随角铺开 = 波

### 板块 5 · 性质与应用
**考点⑨ 五个基本性质（周期/奇偶/值域/单调/对称）**
- 题型入口：求最小正周期 / 判奇偶 / 读单调增区间 / 写对称中心
- 分类：全部从图像或单位圆读出，**一条不背**
- 排除：奇偶靠代公式不靠图像；周期写 π（sin 是 2π）
- 收敛：图像读（峰谷/对称/起落）

**考点⑩ y=A sin(ωx+φ) 第一层（读参数）**
- 题型入口：给解析式，求 A / T / 最值
- 分类：A=振幅，T=2π/ω，最值=±A
- 排除：反求 φ（不讲）；图像变换顺序（不讲）
- 收敛：套三个旋钮，仅读不反求
