## 设计说明（**此段不发给学生**，供主脑校验）

**1. 为什么 30 题只给 30 分钟**
这不是能力测试，是**扫描**。每题限定 1 分钟以内可答完，考的是"反射是否存在"，不是"能不能算出来"。
一道题超过 1 分钟还没方向 → 就是断点，答案本身不重要。

**2. 为什么学生版不标考点（与任务书原文有偏差，请主脑裁定）**
任务书写的是"30 题标考点"。我把**考点标注挪到了老师版对照表**，学生版只留区号题号。两条理由：
- 标了考点等于给提示（看到"考点：一元二次不等式"就知道要因式分解），扫描结果会失真；
- 对 50 分学生，看到一串专业术语会触发"我没学过"的提前放弃，空白率上升。
**如主脑坚持学生版标考点，改回只需在 HTML 每题后加一个灰色标签，5 分钟工作量。**

**3. 为什么 C 区（三角）不考三角公式**
她自述三角未学，考公式必得 0 分，0 信息量。
C 区改考**进入三角的前置件**：坐标定位、勾股、锐角三角比、圆周长、图像读取、符号判断。
→ 这一区决定第 1 课要不要先补件（对应决策库 R3/R4）。**这是全卷信息密度最高的一区。**

**4. 自评标记是本卷的核心设计**
每题必须标 ✓（会）/ ?（猜）/ ✗（不会）。
只看对错只能分出两种状态；**对错 × 自评** 能分出四种：真会 / 假会 / 错会 / 真空。
四种的教学成本完全不同（判读规则见 `04c`）。**没有自评标记，这张卷子的价值损失一半以上。**

**5. 为什么加 F 区（概率统计）和 B 区导数入口（本轮新增，依据期末卷 37.5/150）**
期末原卷显示：概率统计占全卷 **49%（74 分）** 且她接近 0 分；导数应用（切线/极值/含参）也大面积出现。
原诊断卷（A/B/C/D/E）**完全没有覆盖概率统计**，等于对她最大的一块真空闭眼走过。
- F 区（5 题）测"期望定义 / 分布列 / 列联表读数 / 古典概型"四个最底层入口，**全设为真空候选**：预期她大面积空，但空白量直接决定第 9 课抢分模板要做多大。正态/回归不单独出题（纯记忆型，诊断价值低，留第 9 课模板）。
- B 区新增 B7–B9（导数入口 3 题）：测她学校的导数课有没有留下任何反射。写不出 f'(x) 或不知道 f'(x) 是切线斜率 → 导数从零补。
- **F 区与 B 导数都是测量，不是承诺暑假教。** 暑假仍按"三角打底 + 函数地基"主线，概率统计只进第 9 课抢分模板；多测是为了 sizing 准，不是扩面。

## 学生指令（原样发给她）

**同学你好，这不是考试，没有分数，不记成绩。**

这是一张"扫描卷"。我需要知道你现在**哪里是真的会、哪里是模糊的、哪里根本没学过**——这三样我分清了，后面这些课才不会浪费你的时间去讲你已经会的东西。

所以只有三条规矩：

1. **限时 30 分钟**，到点就停。不要为了做完而延长。
2. **不许翻书、不许查手机、不许问人。** 翻书查出来的对，等于把断点藏起来了，最后受损失的是你。
3. **每一题都要在旁边标一个符号**，这一步比答案还重要：
   - **✓** = 我确定会，我知道我为什么这么做
   - **?** = 我做出来了，但我是猜的 / 蒙的 / 记不清了
   - **✗** = 我不会，或者没学过

**不会的题直接空着，标 ✗，然后跳过。** 空着不丢人，标错了才麻烦。
**最后一件事**：如果某题你卡住了，在旁边写一句"卡在哪"（比如"不知道怎么开始""公式忘了""看不懂题目"）。这一句话对我的价值超过一个正确答案。

## A 区（6 题）

A1. 已知集合 A = {1, 2, 3, 4}，B = {2, 4, 6}，求 A ∩ B。

A2. 已知全集 U = {1, 2, 3, 4, 5}，A = {1, 3}，求 A 在 U 中的补集。

A3. 解不等式 x² − x − 6 < 0，并把解集用集合表示。

A4. "x > 2" 是 "x > 1" 的什么条件？（充分不必要 / 必要不充分 / 充要 / 既不充分也不必要，选一个）

A5. 用列举法表示集合 {x | x² = 1}。

A6. 已知 A = {x | x < a}，B = {x | x < 3}。若 A ⊆ B，求 a 的取值范围。

## B 区（6 题）

B1. 求函数 f(x) = 1/(x − 2) + √(x + 1) 的定义域。

B2. 已知 f(x) = x² − 2x，求 f(3)、f(−1)、f(a)。

B3. 求 f(x) = x² − 2x 在区间 [0, 3] 上的最大值和最小值。

B4. 判断下面两个函数的奇偶性：f(x) = x³；g(x) = x² + 1。

B5. 在下面空白处画出 y = 2ˣ 与 y = log₂x 中**任选一个**的大致图像，并标出它必定经过的一个点的坐标。

B6. 已知 f(x) = x²。填空：f(x) 在 (−∞, 0) 上是 ______ 函数，在 (0, +∞) 上是 ______ 函数。（填"增"或"减"）

B7. 已知函数 f(x) = x³，写出它的导数 f'(x) = ______。（提示：xⁿ 的导数是 n·xⁿ⁻¹）

B8. f'(x) 在几何上表示什么？用一句话回答：______。

B9. 曲线 y = x² 在点 (1, 1) 处的切线斜率是多少？______。

## C 区（6 题）

C1. 一个直角三角形的两条直角边长为 3 和 4。(1) 斜边多长？(2) 较小的那个锐角的正弦值等于多少？（用边长的比表示）

C2. 在平面直角坐标系中，点 P(−1, √3)。(1) 它在第几象限？(2) 它到原点 O 的距离 |OP| 是多少？

C3. 一个圆的半径是 2。(1) 它的周长是多少？(2) 半个圆的弧长是多少？

C4. 填出下列各值：sin 30° = ______，sin 45° = ______，sin 60° = ______。

C5. 看下图（一条曲线在坐标系中，x 轴标有刻度 0、π、2π）：(1) 图中曲线的最大值是多少？(2) 这条曲线与 x 轴有几个交点？

> **图见 HTML 版**。若使用本 md 版，请把 HTML 版的 C5 图截图给学生。

C6. 判断符号（填"正"或"负"）：(1) 若 a < 0，b > 0，则 ab 是 ______；(2) 若 a < 0，b < 0，则 a / b 是 ______。

## D 区（6 题）

D1. 数列 2, 5, 8, 11, … 是等差数列，求它的第 10 项 a₁₀。

D2. 接上题，求这个数列前 10 项的和 S₁₀。

D3. 数列 1, 2, 4, 8, … 是等比数列，求它的第 6 项 a₆。

D4. 已知数列的通项公式 aₙ = 2n − 1，求 a₁、a₅，以及 aₙ₊₁（用含 n 的式子表示）。

D5. 在等差数列中，已知 a₃ = 5，a₇ = 13，求公差 d。

D6. 数列 1, 3, 5, 7 是等差数列还是等比数列？它的公差（或公比）是多少？
