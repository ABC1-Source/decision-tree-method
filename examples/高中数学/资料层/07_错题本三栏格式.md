# 07 · 错题本三栏格式（核心交付物）

> 服务：全部课程｜8/15 主脑增量 ②「核心交付=错题闭环，不是知识」
> 第 1 课建立｜闭环：归因 → 3 天后重做 → 变式验证 → 每周日回捞
> 理念：她学会闭环，整个高三自转；只学知识，一个月就忘

---

## 三栏定义

每道错题占一行，三栏必填：

| 栏 | 名称 | 填什么 | 不填的后果 |
|---|---|---|---|
| **栏1** | 归因 | 为什么错：① 知识缺（没学过/忘了）② 计算炸（会做算错）③ 读题偏（看错条件）④ 习惯漏（开闭/符号/单位） | 不归因=白错，同坑必再踩 |
| **栏2** | 3 天后重做 | 日期 + 独立重做结果（✓/✗，不准看答案） | 不重做=假会固化 |
| **栏3** | 变式验证 | 换数/逆问/加陷阱的一道题 + 结果 | 不变式=只记住这道题，不迁移 |

**栏1 归因标注责任层**（接 08 迭代纪律）：标 `S`(学生不会) / `T`(题出难了) / `O`(顺序错)。用于迭代时区分「她的问题」还是「我的问题」。

---

## 闭环节奏（写给她看的版本）

1. **当堂**：错一题 → 栏1 当场写归因（不隔夜）。
2. **3 天后**：独立重做原题 → 栏2 打 ✓/✗。
3. **重做 ✓ 后**：做一道变式 → 栏3 打结果。栏3 ✓ = 真会，闭环完成。
4. **每周日**：把本周三栏全过一遍。栏2 或栏3 仍 ✗ → 回炉，下周重走。

> 周日回捞是闭环的「拧紧螺丝」动作——不回捞，前三条会松掉。
