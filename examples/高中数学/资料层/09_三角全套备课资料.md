## 四、板块1-3 备课卡（condensed，详细脚本见 02）

**板块1 概念与定义**
- 目标：角是旋转记录；弧度是角进函数的门票；sin/cos/tan=坐标。
- 判定：不套公式从坐标读三值 = 过；试图找公式 = 回机制。
- 易错：k∈Z 漏写（终边相同角）；弧度无单位混淆；sin²α≠sin(α²)。

**板块2 符号与诱导**
- 目标：符号由坐标定（推不背）；诱导=单位圆三种对称。
- 判定：先画对称点再写符号 = 过；背答案 = 未过。
- 易错：π/2±α 型（横纵互换）留 L2 收尾或顺延；奇变偶不变中"奇偶"=π/2倍数。

**板块3 图像与性质**
- 目标：五点法画波；从图读周期/值域/单调/对称。
- 判定：独立画五点+读性质 = 过。
- 易错：单调区间写成整体属性；y=Asin 的 T=2π/ω 算错。

## 五、板块4 恒等变换（新写）

### 先教30秒（总纲）
- **是什么**：把复杂的角、复杂的式子，化成能算、能比的单层。
- **机制**：公式是「已知特殊角的值，推出任意角组合的值」的桥梁。起点只有一个：**cos(α−β)**，其余全是它的推论。
- **类比**：乐高——特殊角是基础块，和差公式是拼接法，拼出任意形状。

### 拆到词（推导链，不跳）
1. **cos(α−β) = cosα cosβ + sinα sinβ**
   - 机制：单位圆上两点 A(cosα,sinα)、B(cosβ,sinβ)，夹角 = α−β；向量点积 `A·B = |A||B|cos(α−β) = cos(α−β)`，又 `A·B = cosα cosβ + sinα sinβ`。两式相等即得。**这是唯一需要记的起点。**
2. **cos(α+β)**：把 β 换成 −β，用 cos 偶/sin 奇 → `cosα cosβ − sinα sinβ`。
3. **sin(α±β)**：用 `sin x = cos(π/2−x)` 转成 cos 差公式推出。
4. **tan(α±β)**：上下同除 cosα cosβ。
5. **二倍角**：令 β=α（sin2α=2sinα cosα；cos2α=cos²−sin²=2cos²−1=1−2sin²；tan2α=2tan/(1−tan²)）。
6. **辅助角**：`a sinx + b cosx = √(a²+b²) sin(x+φ)`，`tanφ = b/a`。
   - 机制：提取振幅，合成单正弦。逆向用于化最值/化单一函数。

### 例题（决策树式：看到什么走哪条路）
- 看到「非特殊角求和求值」→ 走和差公式（先拆成特殊角组合）。
- 看到「2α / 平方」→ 走二倍角（注意 cos2α 三选一按已知选最省的一步）。
- 看到「a sinx + b cosx」→ 走辅助角（提 √(a²+b²)）。

### 判定
能独立从 cos(α−β) 推出 sin/tan 和差 = 过；只背不推 = 回机制。二倍角三式能按题选 = 过。

### 易错（高考地雷）
- cos2α 三式混淆，代入时选错导致多算一步。
- 辅助角 φ 的象限（tanφ=b/a 但 φ 可能不在第一象限，需看 a,b 符号定）。
- 和差公式符号（cos 差用 +，cos 和用 −，最易反）。

## 六、板块5 解三角形（新写）

### 先教30秒（总纲）
- **是什么**：已知三角形的一部分（边/角），求其余。
- **机制**：正弦定理管「边角对边角」（比相等），余弦定理管「知三边或两边夹角求第三边」（勾股定理推广）。
- **类比**：余弦定理 = 勾股定理加一个「夹角修正项」；锐角修正为正，钝角修正为负。

### 拆到词
1. **正弦定理**：`a/sinA = b/sinB = c/sinC = 2R`
   - 机制：直径所对圆周角=直角，斜边=2R；任意边与其对角的正弦比=直径。
   - 适用：知两角一边（AAS/ASA）→ 求其余；知两边及一边对角（SSA）→ 可能两解。
2. **余弦定理**：`c² = a² + b² − 2ab cosC`（及轮换）
   - 机制：向量 `|a−b|² = |a|²+|b|²−2a·b`，夹角 C 时点积=ab cosC。
   - 适用：知三边（SSS）→ 求角；知两边夹角（SAS）→ 求第三边。
3. **面积**：`S = ½ ab sinC`（两夹边及夹角）。

### 例题（决策树式）
- 看到「知两角一边」→ 正弦定理（先求第三角，再比）。
- 看到「知两边夹角」→ 余弦定理求对边。
- 看到「知三边」→ 余弦定理求角（注意 cos 符号定钝角/锐角）。
- 看到「求面积」→ ½ ab sinC（先确认有夹角）。

### 判定
能独立判「走正弦还是余弦」并写对 = 过；乱套公式 = 回机制。

### 易错（高考地雷）
- SSA 两解漏判（钝角/锐角都可能）。
- 余弦定理求角时 cos 符号→钝角，误判为锐角。
- 面积公式忘乘 sinC（写成 ½ ab）。
