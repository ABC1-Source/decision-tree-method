## 一、教学铁律 6 条（python-tutor 纪律 → 数学迁移）

1. **先教 30 秒**：每个新符号/公式出现，先 30 秒讲"是什么+机制+日常类比"，再写代码（题）。不闷头写。类比只用钟表/摩天轮/镜子/尺子，不用化学（学生无化学储备，讲类比=多讲一个知识点，违反不跳步）。
2. **拆到词**：概念先给宏观类比，再逐 token 拆代码示例。只给宏观不拆=违规。例：a/sinA=2R 要拆到"2R=外接圆直径，为什么？因为直径所对圆周角=90°"。
3. **机制优先**：讲底层机制（如"缩进=管辖边界"→"单调区间必须带 +k·2π/ω 因为周期重复"），由机制推现象，不贴"坑/注意"标签。
4. **例题只用品组合**：例题/习题只用"已教工具+本节新工具"，不夹带超纲语法。迁移/诊断扩展不夹带未教符号。
5. **做对才算会**：验收标准是"当场独立做对变式"，不是"她点头说懂了"。
6. **不赶进度**：讲不透就停，不进下一模块。板块内判定不过 → 回 M1+M2，不跳。

### 板块1 · 概念与定义（焊于 0D 1.1–1.6）

> 总入口 M0：题干出现"任意角/弧度/终边/坐标求 sin cos tan/象限" → 进本板块。动手前先判象限/轴线。

**【真题雷达】（新高考Ⅰ/Ⅱ真实考情）**：板块1（概念/同角/象限）在新高考Ⅰ/Ⅱ**不单独命制小题**，它是板块3/4/5 的底层地基。下方用一道真实高考题展示它如何被调用——

**① 路由表 · 什么时候用什么解题办法（精髓）**
| 题面特征 | 用哪个办法 | 收敛动作 |
|---|---|---|
| 写"与 α 终边相同的角" | 1.1 任意角 | 必带 +2kπ (k∈Z)，k∈Z 不可省 |
| 度数 ↔ 弧度换算 | 1.2 弧度制 | ×π/180（度→弧），结果标 rad 不写° |
| 给终边点/坐标求三值 | 1.3 定义 | 先算 r=√(x²+y²)，从 P(x,y) 读；x=0 时 tan 不存在 |
| 给 sin/cos/tan 之一求另俩 | 1.5 同角关系 | 切化弦或平方关系，先定符号再算 |
| 判 sin/cos/tan 正负 | 1.6 象限符号 | 口诀"一全正二正弦三切四余弦" |
| [选学] 图像题读有向线段 | 1.4 三角函数线 | 由单位圆读正弦线/余弦线/正切线 |

> **决策口诀（板块1精髓）**：一切从单位圆 P(x,y) 读，不背公式；**轴线角（在坐标轴上）单独拎出来单列，别和象限角混**。板块1 是地基，路由维度低（几乎一一对应），唯一会绊人的决策点就是"轴线角单列"。

**② 解题办法（每个办法 = 怎么用）**
- **★1.1 任意角**：角是"转出来的量"，终边相同角差整数圈 → 通解 +2kπ。教案动作：给角先判象限/轴线，写通解必带 k∈Z。示范句："与α终边相同角：β=α+2kπ(k∈Z)"。当堂判定：给3角（含轴线）写通解，漏 k∈Z=不过。归因：漏 k∈Z→习惯漏(O)。
- **★1.2 弧度制**：弧度=弧长/半径，无单位。教案动作：度→弧 ×π/180；结果标 rad。示范句："60°=π/3(rad)"。归因：写成°或漏 rad→习惯漏(O)。
- **★1.3 定义（单位圆）**：从 P(x,y) 读 sin=y/r,cos=x/r,tan=y/x。教案动作：给坐标先算 r 再读三值；x=0 时 tan 不存在。示范句："P(3,4),r=5→sin=4/5,cos=3/5,tan=4/3"。归因：tan 漏 x=0→习惯漏(O)。
- **★1.5 同角关系**：sin²+cos²=1（勾股）；切化弦 tan=sin/cos。教案动作：见 tan 先化 sin/cos；由一角求另俩先定符号。示范句："sinα=3/5 且 α 在Ⅱ→cos=-4/5,tan=-3/4"。归因：符号漏±→习惯漏(O)。
- **★1.6 象限符号**：口诀定正负。教案动作：先定象限再落符号，轴线角单列。示范句："α在Ⅲ→sin<0,cos<0,tan>0"。归因：口诀背错→知识缺(S)。
- **▲1.4 三角函数线**（选学）：定义证明/图像题启用，能由单位圆读三条有向线段即可。

**③ 知识点地基（浓缩，只记必记）**
终边相同角 β=α+2kπ(k∈Z) ｜ 弧度 l=|α|r ｜ 定义 sin=y/r,cos=x/r,tan=y/x ｜ 同角 sin²+cos²=1,tan=sin/cos ｜ 象限符号"一全正二正弦三切四余弦"

**④ M2 红线（高失分点必经）**
- ⚠ 弧度写成°或漏 rad → 必经：结果标 rad
- ⚠ 终边相同角漏 k∈Z → 必经：所有通解带 k∈Z
- ⚠ sin²α 误当 sin(α²) → 必经：审题区分平方位置
- ⚠ 轴线角符号误判 → 必经：轴线情形单独列
**⑤ 真题跑通示例（板块1 · 同角关系地基调用示范）**
【2022 新高考Ⅱ T6】角α,β 满足 sinαcosβ+cosαsinβ+sinαcosβ-cosαsinβ=2cosαsinβ，则 tanα=（ ）A.… B.… C.… D.1
→ 路由触发：给“含 sin/cos 乘积的等式” → 主归板块4（和差公式化简）；但化简落点 tanα=sinα/cosα 调用了**板块1.5 同角商数关系**这一地基。
→ 跑通：左=sin(α+β)+sin(α-β)=2sinαcosβ，右=2cosαsinβ → 2sinαcosβ=2cosαsinβ → sinαcosβ=cosαsinβ → 两边同÷cosαcosβ 得 tanα=tanβ；结合题设推得 tanα=1（多源确认答案 D）。
→ 锚定：同角商数关系 tanα=sinα/cosα 是板块1 的核心地基，恒等变换最终常落回它——这就是板块1 在新高考里的真实存在方式（不单独考，但每道三角题都踩它）。

### 板块2 · 符号与诱导（焊于 0D 2.1–2.4）

> 总入口 M0：题干含 -α / π±α / 2π-α / π/2±α / 3π/2±α → 进本板块。先定原角所在象限。

**【真题雷达】（新高考Ⅰ/Ⅱ真实考情）**：板块2（诱导公式）在新高考Ⅰ/Ⅱ**几乎不单独命制小题**，诱导并入板块4 恒等变换的“第一步变形”。下方用真实新高考题展示它如何被调用——

**① 路由表 · 什么时候用什么解题办法（精髓）**
| 诱导角类型 | 用哪个办法 | 收敛动作 |
|---|---|---|
| 任何诱导前，先定原角象限 | 2.1 象限符号 | 符号由终边象限唯一确定 |
| 名不变组：-α, π±α, 2π-α | 2.2 基础组 | 名不变（sin 还是 sin），只定符号 |
| π/2±α, 3π/2±α | 2.3 π/2 组 | 数 π/2 倍数奇偶→变名与否；视 α 锐角定符号 |
| [选学] 证明/图象对称推导 | 2.4 对称性推导 | 由奇偶/周期推中心轴 |

> **决策口诀（板块2精髓，真正的二分支决策树）**：**第一步数"π/2 的倍数"奇偶——奇则变名（sin↔cos、tan↔cot），偶则不变；第二步"符号看象限"——视 α 为锐角代回原式定正负。** 先判"变不变名"再"定符号"，顺序不能反。

**② 解题办法（每个办法 = 怎么用）**
- **★2.1 象限符号**：诱导前先定原角象限。教案动作：画象限圈标原角再落符号。示范句："α在Ⅱ→sinα>0,cosα<0"。归因：象限判错→知识缺(S)。
- **★2.2 基础组**（-α/π±α/2π-α）：名不变，只看符号。教案动作：套前念"名不变，符号看原象限"；sin(-α)=-sinα, cos(π-α)=-cosα…。示范句："sin(π-α)=sinα（Ⅱ sin 正）"。归因：符号错→习惯漏(O)。
- **★2.3 π/2 组**（π/2±α/3π/2±α）：奇变偶不变。教案动作：画单位圆对称点；先判奇偶→变名与否→视α锐角定符号。示范句："sin(π/2-α)=cosα；cos(π/2+α)=-sinα"。归因：sin↔cos搞反→机制没懂(T)；符号错→习惯漏(O)。
- **▲2.4 对称性推导**（选学）：大题证明/图象对称启用，由奇偶周期推中心轴。

**③ 知识点地基（浓缩）**
基础组：sin(-α)=-sinα, cos(-α)=cosα, sin(π-α)=sinα, cos(π-α)=-cosα ｜ π/2 组：奇变偶不变、符号看象限

**④ M2 红线（高失分点必经）**
- ⚠ π/2±α 横纵互换搞反 → 必经：先判 π/2 倍数奇偶
- ⚠ "符号看象限"把 α 当锐角代（实际任意角）→ 必经：视 α 为锐角定符号、代回原式
- ⚠ 忘"偶不变"指 π/2 偶数倍不变名 → 必经：数 π/2 倍数奇偶
**⑤ 真题跑通示例（板块2 · 诱导/和差公式地基调用示范）**
【2024 新高考Ⅰ T4】已知 cos(α+β)=m，tanαtanβ=2，则 cos(α-β)=（ ）A.-3m B.-m/3 C.m/3 D.3m
→ 路由触发：主归板块4（恒等变换）；但其**第一步**把 cos(α+β) 拆成 cosαcosβ-sinαsinβ，正是板块2.2 基础组“差+和-”意识的落地。
→ 跑通（同板块4 主示例）：cos(α+β)=cosαcosβ-sinαsinβ=m；tanαtanβ=2 ⇒ sinαsinβ=2cosαcosβ ⇒ cosαcosβ=-m，sinαsinβ=-2m ⇒ cos(α-β)=cosαcosβ+sinαsinβ=-3m。答案 A。
→ 锚定：诱导/和差公式（板块2）是板块4 恒等变换的“第一把刀”——新高考里它不单独考，但每道综合题都先走这一步。

### 板块3 · 图像与性质（焊于 0D 3.1–3.12）

> 总入口 M0：题干出现"解析式/周期/单调/对称/最值/y=Asin(ωx+φ)/图象变换" → 进本板块。统一动作：换元 t=ωx+φ 化归标准式。

**【真题雷达】（新高考Ⅰ/Ⅱ真实题）**：2024新高考ⅡT9（周期/对称轴/零点/最值多选）；2024新高考ⅠT7（交点个数）；2023新高考ⅠT15（零点个数求ω范围）

**① 路由表 · 什么时候用什么解题办法（精髓，同构板块5"题型→方法"）**
| 题面问什么 | 用哪个办法 | 收敛动作 |
|---|---|---|
| 求周期 T | 3.3 | T=2π/|ω|（tan 用 π/|ω|），取绝对值 |
| 求单调区间 | 3.5 | 换元 t=ωx+φ，代回标准单调区间，必带 +k·2π/ω |
| 求对称中心/轴 | 3.6 | 中心令 ωx+φ=kπ，轴令=kπ+π/2 |
| 求最值/值域 | 3.4 | 极值 ±|A|+B，值域[-|A|+B,|A|+B] |
| 给图求解析式 | 3.8 | A=峰谷差/2，ω=2π/T，φ 代零点/最值点 |
| 徒手画图 | 3.1 五点法 / 3.2 图象 | 取五相位算点；tan 必画渐近线 |
| 图象变换 | 3.9 | 先平移后伸缩 vs 先伸缩后平移，平移量差 ω 倍 |
| 判奇偶 | 3.7 | 代 -x 判 |
| 综合性质（统一动作） | 3.10 整体换元 | 令 t=ωx+φ 化归标准式再算 |
| [选学] 多条件列参 | 3.11 | 单调/对称/最值条件→列参数方程 |
| [选学] ω 范围 | 3.12 | 由点/区间列 ω 不等式 |

> **决策口诀（板块3精髓）**：**"问什么性质，就用哪个公式"——路由是 题面问X→用3.X；但所有 3.X 共享一个底层动作：换元 t=ωx+φ 化归标准式，在 t 上算完再换回 x。** 板块3 没有"选哪个大法"的纠结，纠结的是"别漏通式/别错顺序"。

**② 解题办法（每个办法 = 怎么用）**
- **★3.3 周期**：T=2π/|ω|（tan 为 π/|ω|）。教案动作：永远取绝对值。示范句："y=sin3x→T=2π/3"。归因：漏|ω|或忘tan→习惯漏(O)。
- **★3.5 单调**：换元 t=ωx+φ 代回。教案动作：结果必带 +k·2π/ω；ω<0 先提负号。示范句："y=sin2x 单增：x∈[-π/4+kπ,π/4+kπ]"。归因：当整体属性写（漏通式）→习惯漏(O)。
- **★3.6 对称**：中心令=kπ，轴令=kπ+π/2。教案动作：sin 中心(kπ,0)/轴 x=π/2+kπ。示范句："y=sin(2x+π/3) 中心：x=-π/6+kπ/2"。归因：中心误用轴公式→机制没懂(T)。
- **★3.4 值域最值**：极值 ±|A|+B。示范句："y=2sinx+1→最值3和-1"。归因：B漏→计算炸(S)。
- **★3.8 y=Asin 解析式**：A=峰谷差/2，ω=2π/T，φ 代零点。示范句："峰谷差4→A=2；T=π→ω=2；过(0,1)→φ=π/6"。归因：φ代错点→计算炸(S)。
- **★3.1 五点法 / ★3.2 图象**：取 ωx+φ=0,π/2,π,3π/2,2π 算点；tan 必画渐近线。归因：tan 渐近线漏→知识缺(S)。
- **★3.7 奇偶**：代 -x 判。归因：φ 干扰→知识缺(S)。
- **★3.9 变换**：先平移后伸缩 vs 先伸缩后平移结果不同。示范句："两种顺序平移量差 ω 倍"。归因：顺序错→机制没懂(T)。
- **★3.10 整体换元**：令 t=ωx+φ 化归标准式。教案动作：算完必换回 x。归因：换回漏→习惯漏(O)。
- **▲3.11 四条件翻译 / ▲3.12 ω范围**（选学）：中档大题/压轴启用，能列参数方程或 ω 不等式即可。

**③ 知识点地基（浓缩）**
换元 t=ωx+φ 是总动作 ｜ T=2π/|ω| ｜ 单调带 +k·2π/ω ｜ 对称 中心kπ/轴kπ+π/2 ｜ 最值 ±|A|+B ｜ 解析式 A=峰谷差/2,ω=2π/T

**④ M2 红线（高失分点必经）**
- ⚠ T=2π/ω 漏|ω|或 ω 为负 → 必经：取绝对值
- ⚠ 单调区间当整体属性写 → 必经：写 +k·2π/ω 通式
- ⚠ 先平移后伸缩顺序错 → 必经：区分两种顺序平移量
- ⚠ 对称中心误用对称轴公式 → 必经：sin 中心(kπ,0)/轴 x=π/2+kπ
**⑤ 真题跑通示例（板块3 · 图像与性质）**
【2024 新高考Ⅰ T7】当 x∈[0,2π] 时，曲线 y=sinx 与 y=2sin(3x-π/6) 的交点个数为（ ）A.3 B.4 C.6 D.8
→ 路由触发：问“两曲线交点个数” → 板块3 路由“徒手画图/数交点”分支 → 用周期+五点法各画一周期数交点。
→ 跑通：y=sinx 的 T=2π，在[0,2π]恰1个完整周期；y=2sin(3x-π/6) 的 T=2π/3，在[0,2π]有3个完整周期，振幅2包住 sinx（振幅1）；每个 sinx 波段内，振幅2的曲线必上下各穿越 sinx 2次 → 3周期×2=6个交点。
→ 答案：C（6个）。锚定 M2 红线：别用代数联立硬解，图像法最快；忘数周期数会漏。

【2024 新高考Ⅱ T9（多选）】对 f(x)=sin2x 与 g(x)=sin(2x-π/4)，下列正确的有（ ）A.相同零点 B.相同最大值 C.相同最小正周期 D.相同对称轴
→ 路由触发：给“两函数比性质” → 板块3 路由“周期/最值/对称轴/零点分别判定”（板块3 核心：图象与性质）。
→ 跑通：T 均=π(C对)；最大值均=1(B对)；零点 f:2x=kπ→x=kπ/2，g:2x-π/4=kπ→x=π/8+kπ/2（不同，A错）；对称轴 f:2x=π/2+kπ→x=π/4+kπ/2，g:2x-π/4=π/2+kπ→x=3π/8+kπ/2（不同，D错）。答案 BC。
→ 锚定：本题原被错放进板块1/2，真实归属是板块3——考的全是 y=Asin(ωx+φ) 的图象性质，与“概念定义”“符号诱导”无关。

### 板块4 · 恒等变换（焊于 0D 4.1–4.12）

> 总入口 M0：题干含 α±β / 2α / a sinx+b cosx / 证明三角等式 → 进本板块。先判断"拆 / 合 / 证"哪条路。

**【真题雷达】（新高考Ⅰ/Ⅱ真实题）**：2024新高考ⅠT4（切化弦+和差→-3m）；2023新高考ⅠT8（给差角正弦+乘积→cos(2α+2β)）

**① 路由表 · 什么时候用什么解题办法（精髓，三分支决策树）**
| 题面特征 | 用哪个办法 | 收敛动作 |
|---|---|---|
| 非特殊角求和差（如 cos15°） | 4.1 和差 | 拆成特殊角组合，符号"差+和-" |
| 见 2α 或平方项 | 4.2 二倍 | cos2α 三式选"已知什么用哪式"最省一步 |
| a sinx+b cosx 合成 | 4.3 辅助角 | √(a²+b²)sin(x+φ)，φ 由 a,b 符号定 |
| 化简求值（复杂式） | 4.5–4.8 | 切化弦+三大统一（统一名/角/次） |
| 半角/积化和差/万能 | 4.9–4.11 | 压轴专用，t=tan(α/2) 等 |
| 证明恒等式 | 4.12 | 先统一名与角，左推右或两边化同 |

> **决策口诀（板块4精髓，三分支决策树）**：**第一步判"拆/合/证"——看到和差先"拆"成特殊角(4.1)，看到 a sinx+b cosx 先"合"成辅助角(4.3)，看到等式先"统一名角再证"(4.12)；第二步在拆/合内部选最省一步的式（cos2α 三式选已知量那式、φ 据 a,b 符号定象限）。** 板块4 的路由纠结点是"选哪式最省"，不是"用不用公式"。

**② 解题办法（每个办法 = 怎么用）**
- **★4.1 和差**：非特殊角求和差→拆特殊角。教案动作："差+和-"：cos(α-β) 用 +，cos(α+β) 用 -。示范句："cos(α-β)=cosαcosβ+sinαsinβ"。归因：符号反→习惯漏(O)。
- **★4.2 二倍**：见 2α/平方→二倍；cos2α 三式选最省一步。教案动作：已知 sin 用 1-2sin²，已知 cos 用 2cos²-1；α 范围未知 cos2α 正负保留 ±。示范句："已知 sinα→cos2α=1-2sin²α"。归因：三式选错多算→习惯漏(O)；α 范围未知符号→机制没懂(T)。
- **★4.3 辅助角**：a sinx+b cosx=√(a²+b²)sin(x+φ)。教案动作：提振幅；φ 由 tanφ=b/a 且据 a,b 符号定象限。示范句："√3 sinx+cosx=2sin(x+π/6)"。归因：φ 象限错→习惯漏(O)。
- **★4.4 化简A型**：即辅助角应用，同 4.3。
- **★4.12 恒等式证明**：统一名/角，左推右或两边化同。教案动作：先切化弦、倍角化单角。示范句："证 tanα-sinα=tanα·sin²α：左=…=右"。归因：不统一名硬推→机制没懂(T)。
- **▲4.5–4.11**（选学）：综合大题/压轴——4.5 化简f型(切化弦+辅助角)、4.6 构造tan/万能、4.7 s+c,s-c,sc、4.8 三大统一、4.9 半角、4.10 积差。能独立完成该型一题即可。

**③ 知识点地基（浓缩）**
和差符号"差+和-" ｜ cos2α 三式 cos²-sin²/2cos²-1/1-2sin² ｜ 辅助角 √(a²+b²)sin(x+φ) ｜ 证明先统一名角

**④ M2 红线（高失分点必经）**
- ⚠ cos2α 三式选错多算一步 → 必经：选最省一步的式
- ⚠ 辅助角 φ 象限（只算 tanφ=b/a）→ 必经：据 a,b 符号定 φ 象限
- ⚠ 和差符号反（cos差用+、cos和用-）→ 必经：背"差+和-"
- ⚠ 二倍角符号（α 范围未知时 cos2α 正负）→ 必经：保留 ± 或依范围定
**⑤ 真题跑通示例（板块4 · 恒等变换）**
【2024 新高考Ⅰ T4】已知 cos(α+β)=m，tanα tanβ=2，则 cos(α-β)=（ ）A.-3m B.-m/3 C.m/3 D.3m
→ 路由触发：给“和角余弦 + 两角正切积” → 板块4 三分支走“拆(4.1和差展开)+切化弦(4.1机制)”合并路。
→ 跑通：由 tanαtanβ=2 ⇒ sinαsinβ/cosαcosβ=2 ⇒ sinαsinβ=2cosαcosβ…①；由 cos(α+β)=m ⇒ cosαcosβ-sinαsinβ=m…②；①代②：cosαcosβ-2cosαcosβ=m ⇒ cosαcosβ=-m，故 sinαsinβ=-2m；则 cos(α-β)=cosαcosβ+sinαsinβ=-m+(-2m)=-3m。
→ 答案：A（-3m）。锚定：核心机制“切化弦+和差公式展开成方程组”，不是死记 cos(α-β) 公式。

### 板块5 · 解三角形（焊于 0D 5.1–5.26，最密，补原09弱项）

**【真题雷达】（新高考Ⅰ/Ⅱ真实题）**：2024新高考ⅠT15（余弦定理定角）；2023新高考ⅠT17（角关系+和差）；2022新高考ⅠT18（边角混合+基本不等式求范围）


**总入口 M0**：题干有"边角关系/求边/角/面积/实际测量"→先判用正弦还是余弦。
**总选定理口诀（M1 入口动作，备好）**："两角一边用正弦，三边夹角用余弦，边角混了一起化，求面积就找公式。"

**★5.1 正弦定理**：先教30秒：a/sinA=b/sinB=c/sinC=2R。机制：2R=外接圆直径（直径所对圆周角=90°）。当堂判定：给两角一边求边，对=过。归因：sin 值代错→计算炸(S)。
**★5.2 正弦四变式**：先教30秒：a=2RsinA / sinA=a/2R / a:b:c=sinA:sinB:sinC。机制：边角互化的四种写法。当堂判定：边化角或设 k，对=过。归因：比例当边长直接代→机制没懂(T)。
**★5.3 余弦定理**：先教30秒：c²=a²+b²-2ab cosC 及轮换。机制：勾股定理的推广（C=90°时退化为勾股）。当堂判定：给三边求角，对=过。归因：符号错→计算炸(S)。
**★5.4 余弦变形**：先教30秒：cosC=(a²+b²-c²)/2ab。机制：由边反求角。教案动作：分子顺序 (a²+b²-c²) 对照记。当堂判定：求 cosC，对=过。归因：分子顺序代错→习惯漏(O)。
**★5.5 比例问题**：先教30秒：a:b:c=sinA:sinB:sinC，统一比例设 k。当堂判定：设 k 求边，对=过。归因：比例当边长→机制没懂(T)。
**★5.6 面积五式**：先教30秒：½ab sinC / ½bc sinA / ½ac sinB / pr / abc/4R。机制：夹角的两边乘 sin。教案动作：⚠面积公式必带 sin（易漏写 ½ab）。当堂判定：给边角求面积，带 sin=过。归因：忘×sinC→习惯漏(O)。
**★5.8 外接圆 R**：先教30秒：R=abc/(4S)=a/(2sinA)。机制：接 5.1 的 2R。当堂判定：求 R，对=过。归因：4S 漏→计算炸(S)。
**★5.9 内切圆 r/半周长 p**：先教30秒：r=S/p, p=(a+b+c)/2。机制：面积=半周长×内切圆半径。当堂判定：求 r/p，对=过。归因：p 与周长混淆→习惯漏(O)。
**★5.10 周长/半周长**：先教30秒：L=a+b+c, p=L/2。当堂判定：区分 L 与 p。归因：混淆→习惯漏(O)。
**★5.11 角化边**：先教30秒：用正弦/余弦把角换成边。当堂判定：化边化简，对=过。归因：方向错→机制没懂(T)。
**★5.12 边化角**：先教30秒：用正弦把边换成角。当堂判定：边化角，对=过。归因：方向错→机制没懂(T)。
**★5.13 角的取舍**：先教30秒：SSA 可能多解。机制：大边对大角——边长越大对角越大。教案动作（备好·门板比喻）："门板（长边）撑得开的角度大，短边撑不开那么大角；所以算出的角要和大边对大角对得上，否则舍去。"当堂判定：给 SSA 写出取舍判断过程（不只答案）=过。归因：漏取舍→机制没懂(T)。
**★5.14 SSA两解**：先教30秒：h=b sinA 与 a 比较定解数（a<h 无解；a=h 一解；b>a>h 两解；a≥b 一解）。教案动作（采分点示范句，备好）："∵a=3,b=4,A=30°，b·sinA=2，h=2<a=3<b=4，∴两解。"当堂判定：给 SSA 算 h 比 a 定 0/1/2 解，写过程=过。归因：漏判两解→习惯漏(O)；h 算错→计算炸(S)。
**★5.18 实际应用**：先教30秒：先建系/画示意图。当堂判定：给测量题画图标已知。归因：不画图→读题偏(O)。
**★5.19 测量术语表**：先教30秒：仰角/俯角/方位角/基线/视角/坡度先标图。当堂判定：给术语标图，对=过。归因：术语不懂未标图→读题偏(O)。
**★5.26 大题综合**：先教30秒：正弦+余弦+面积联立。当堂判定：做一道 13分 综合题（走 5.3+5.6 或 5.1+5.15），对=过。归因：综合错→知识缺(S)或计算炸。
**▲5.7 射影定理 / ▲5.15 高线 / ▲5.16 中线角平分线长 / ▲5.17 几何计算**：选学，大题几何综合启用。开课按需补话术；判定=能由 a=b cosC+c cosB 或面积/余弦求线长；归因=知识缺(S)。
**▲5.20 最值(基本不等式) / ▲5.21 最值(三角函数) / ▲5.22 切弦互化最值 / ▲5.23 多边形(含确定△) / ▲5.24 多边形(不含确定△) / ▲5.25 解三角内恒等式**：选学，中档/压轴大题启用（2024T15 面积最值、2023T17 范围）。开课按需补话术；判定=能独立完成该型一题；归因=知识缺(S)/计算炸。

**⑤ 真题跑通示例（板块5 · 解三角形）**
【2023 新高考Ⅰ T17】已知△ABC 中，A+B=3C，2sin(A-C)=sinB。（1）求 sinA；（2）设 AB=5，求 AB 边上的高。
→ 路由触发：给"角关系 A+B=3C + 含角等式" → 板块5 路由"先用内角和化去一个角，再用和差公式"。
→ 跑通：(1) A+B+C=π 且 A+B=3C ⇒ 4C=π ⇒ C=π/4；2sin(A-C)=sinB=sin(A+C) ⇒ 2sinAcosC-2cosAsinC=sinAcosC+cosAsinC ⇒ sinAcosC=3cosAsinC ⇒ 代入 C=π/4(cosC=sinC=√2/2) ⇒ sinA=3cosA；由 sin²A+cos²A=1 ⇒ sinA=3√10/10。(2) 正弦定理 a/sinA=b/sinB=c/sinC，AB=c=5；sinB=sin(A+C)=sinAcosC+cosAsinC=(3√10/10)(√2/2)+(√10/10)(√2/2)=2√5/5；b=AB·sinA/sinC=5·(3√10/10)/(√2/2)=3√5；AB 边高 h=b·sinA=3√5·3√10/10=6（或面积 ½ch=½bc sinA 同得 h=6）。
→ 答案：(1) sinA=3√10/10；(2) 高=6。锚定：角关系题先化内角和，再统一成单角正弦/余弦。
