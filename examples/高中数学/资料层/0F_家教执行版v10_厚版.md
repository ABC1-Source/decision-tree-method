## 一、教学铁律 6 条（python-tutor 纪律 → 数学迁移）

1. **先教 30 秒**：每个新符号/公式出现，先 30 秒讲"是什么+机制+日常类比"，再写代码（题）。不闷头写。类比只用钟表/摩天轮/镜子/尺子，不用化学（学生无化学储备，讲类比=多讲一个知识点，违反不跳步）。
2. **拆到词**：概念先给宏观类比，再逐 token 拆代码示例。只给宏观不拆=违规。例：a/sinA=2R 要拆到"2R=外接圆直径，为什么？因为直径所对圆周角=90°"。
3. **机制优先**：讲底层机制（如"缩进=管辖边界"→"单调区间必须带 +k·2π/ω 因为周期重复"），由机制推现象，不贴"坑/注意"标签。
4. **例题只用品组合**：例题/习题只用"已教工具+本节新工具"，不夹带超纲语法。迁移/诊断扩展不夹带未教符号。
5. **做对才算会**：验收标准是"当场独立做对变式"，不是"她点头说懂了"。
6. **不赶进度**：讲不透就停，不进下一模块。板块内判定不过 → 回 M1+M2，不跳。

### 板块1 · 概念与定义（焊于 0D 1.1–1.6）

> 总入口 M0：题干出现"任意角/弧度/终边/坐标求 sin cos tan/象限" → 进本板块。动手前先判象限/轴线。
> 总口诀（备好）：象限符号"一全正二正弦三切四余弦"；轴线角（坐标轴上）单独拎出来单列，别和象限混。

**★1.1 任意角**
- 先教30秒：角是"转出来的量"，不是图形里的尖。转一圈=2π(rad)。机制：终边相同角差整数圈 → 通解必 "+2kπ(k∈Z)"。类比：钟表转3圈和转1圈都回12点。
- 教案动作（备好·口诀）：①给任意角先判象限/轴线；②写通解必写 "+2kπ, k∈Z"，一套到底。示范句："与α终边相同角：β=α+2kπ (k∈Z)"。
- 当堂判定：给 3 个角（含轴线角）写通解，全对=过；漏 k∈Z 或漏"k∈Z"=不过。
- 错题归因：漏 k∈Z→习惯漏(O)；象限判错→知识缺(S)。

**★1.2 弧度制**
- 先教30秒：弧度是"弧长/半径"，无单位（rad 写不写都行，但绝不能写成 °）。机制：弧长 l=|α|r。类比：用"圈数"量角比用"度数"直接。
- 教案动作（备好·口诀）：度→弧度 ×π/180；弧度→度 ×180/π；结果标 rad 不写 °。示范句："60° = 60×π/180 = π/3 (rad)"。
- 当堂判定：给 60°/120° 化弧度、给 π/3 化角度，全对=过。
- 错题归因：写成 ° 或漏 rad→习惯漏(O)；公式用反→知识缺(S)。

**★1.3 定义（单位圆）**
- 先教30秒：别背公式，从 P(x,y) 读：sin=y/r, cos=x/r, tan=y/x。机制：r=√(x²+y²)>0。类比：坐标就是角的"地址"。
- 教案动作（备好·示范句）：给坐标先算 r 再读三值；轴线角（x=0 或 y=0）单独列——x=0 时 tan 不存在。示范句："P(3,4), r=5 → sin=4/5, cos=3/5, tan=4/3"。
- 当堂判定：给 3 个终边点（含轴线点）求三值，全对=过。
- 错题归因：tan 漏 x=0 不存在→习惯漏(O)；r 算错→计算炸(S)。

**★1.5 同角关系**
- 先教30秒：sin²+cos²=1 是勾股定理；切化弦 tan=sin/cos。机制：统一名才好算。
- 教案动作（备好·口诀）：见 tan 先化 sin/cos；见 sin² 想 1−cos²（两根 ±）；由一角求另两值先定符号。示范句："已知 sinα=3/5 且 α 在第二象限 → cosα=−4/5, tanα=−3/4"。
- 当堂判定：给 sin 求 cos/tan（含符号判定），全对=过。
- 错题归因：符号漏 ±→习惯漏(O)；公式混→知识缺(S)。

**★1.6 象限符号**
- 先教30秒：口诀"一全正二正弦三切四余弦"定正负。机制：看终边落在哪象限定符号。
- 教案动作（备好·口诀+小图）：先定象限再落符号，画小图辅助；轴线角（x轴/y轴上）正负按定义单列。示范句："α 在第三象限 → sin<0, cos<0, tan>0"。
- 当堂判定：给角判 sin/cos/tan 正负，全对=过。
- 错题归因：口诀背错→知识缺(S)；轴线角误判→习惯漏(O)。

**▲1.4 三角函数线**：选学，定义证明/选择题图像题启用。开课按需补话术；当堂判定=能由单位圆读出正弦线 MP/余弦线 OM/正切线 AT；归因=知识缺(S)。

### 板块2 · 符号与诱导（焊于 0D 2.1–2.4）

> 总入口 M0：题干含 −α / π±α / 2π−α / π/2±α / 3π/2±α → 进本板块。先定原角所在象限再落符号。
> 总口诀（备好）："奇变偶不变，符号看象限"——数 π/2 的倍数奇偶决定变不变名，视 α 为锐角定符号代回原式。

**★2.1 象限符号**
- 先教30秒：诱导前先知道原角在第几象限。机制：符号由终边象限唯一确定。
- 教案动作（备好·小图）：先画象限圈标原角，再落符号。示范句："α 在第二象限 → sinα>0, cosα<0"。
- 当堂判定：给诱导角判符号，对=过。
- 错题归因：象限判错→知识缺(S)。

**★2.2 诱导基础组**（−α / π±α / 2π−α）
- 先教30秒：这组"名不变"（sin 还是 sin，cos 还是 cos），只看符号。机制：符号看原象限。
- 教案动作（备好·口诀）：套公式前先念"名不变，符号看原象限"；sin(−α)=−sinα, cos(−α)=cosα, sin(π−α)=sinα, cos(π−α)=−cosα。示范句："sin(π−α)=sinα（第二象限 sin 正）"。
- 当堂判定：给 3 题化到锐角，全对=过。
- 错题归因：符号错→习惯漏(O)。

**★2.3 诱导 π/2 组**（π/2±α / 3π/2±α）
- 先教30秒："奇变偶不变、符号看象限"——数 π/2 的倍数奇偶决定变不变名（奇变 sin↔cos、tan↔cot），视 α 为锐角定符号代回。机制：单位圆上的对称点。
- 教案动作（备好·单位圆+示范句）：画单位圆对称点；先判 π/2 倍数奇偶→变名与否→视 α 锐角定符号。示范句："sin(π/2−α)=cosα；cos(π/2+α)=−sinα（α 锐角时第二象限 cos 负）"。
- 当堂判定：给 π/2±α、3π/2±α 化简，全对=过。
- 错题归因：sin↔cos 搞反→机制没懂(T)；符号错→习惯漏(O)。

**▲2.4 对称性推导**：选学，大题证明/图象对称启用。开课按需补；判定=能由奇偶/周期推中心轴；归因=知识缺(S)。

### 板块3 · 图像与性质（焊于 0D 3.1–3.12）

> 总入口 M0：题干出现"解析式/周期/单调/对称/最值/y=Asin(ωx+φ)/图象变换" → 进本板块。统一动作：换元 t=ωx+φ 化归标准式。
> 总口诀（备好）："所有性质在 t 上算，再换回 x"——周期/单调/对称/最值全部先归标准再解。

**★3.1 五点法**
- 先教30秒：取 ωx+φ=0, π/2, π, 3π/2, 2π 算 x,y，五点定一周期。机制：控制相位取满一个周期。
- 教案动作（备好·示范句）：列表 x 由 ωx+φ=五个值反解，y 代 sin 值。示范句："y=sin2x：ωx=0,π/2,… → x=0,π/4,π/2,…"。
- 当堂判定：给 y=sin(2x) 列五点，对=过。
- 错题归因：φ 漏→习惯漏(O)。

**★3.2 图象**
- 先教30秒：sin 过原点波浪、cos 起点峰、tan 分段带渐近线。机制：由定义看趋势。
- 教案动作（备好·口诀）：tan 必画竖直渐近线 x=π/2+kπ；三图徒手画先标关键点。示范句："tanx 在 (−π/2,π/2) 单调增，两端趋向 ±∞"。
- 当堂判定：徒手画三图，对=过。
- 错题归因：tan 渐近线漏→知识缺(S)。

**★3.3 周期**
- 先教30秒：T=2π/|ω|（tan 为 π/|ω|）。机制：ω 管"挤密"，|ω| 越大周期越短。
- 教案动作（备好·口诀）：永远取绝对值；tan 单独记 π/|ω|。示范句："y=sin(3x) → T=2π/3"。
- 当堂判定：给解析式求 T，对=过。
- 错题归因：漏 |ω| 或忘 tan→习惯漏(O)。

**★3.4 值域最值**
- 先教30秒：极值=±|A|+B。机制：sin/cos 被 A 拉伸、B 平移。
- 教案动作（备好·口诀）：先提 |A| 再 ±B；值域 [−|A|+B, |A|+B]。示范句："y=2sin x+1 → 最值 3 和 −1"。
- 当堂判定：给 A,B 求最值，对=过。
- 错题归因：B 漏→计算炸(S)。

**★3.5 单调**
- 先教30秒：换元 t=ωx+φ 代回标准单调区间解 x。机制：先归标准再解。
- 教案动作（备好·口诀）：结果必带 +k·2π/ω 通式（周期重复）；ω<0 先提负号。示范句："y=sin(2x) 单增：−π/2+2kπ≤2x≤π/2+2kπ → x∈[−π/4+kπ, π/4+kπ]"。
- 当堂判定：求单增区间，带 +k·2π/ω 通式=过。
- 错题归因：当整体属性写（漏通式）→习惯漏(O)；ω 符号→计算炸(S)。

**★3.6 对称**
- 先教30秒：中心令 ωx+φ=kπ，轴令 =kπ+π/2。机制：sin 零点在 kπ、峰在 π/2+kπ。
- 教案动作（备好·口诀）：sin 中心(kπ,0)/轴 x=π/2+kπ；cos 中心(π/2+kπ,0)/轴 x=kπ。示范句："y=sin(2x+π/3) 对称中心：2x+π/3=kπ → x=−π/6+kπ/2"。
- 当堂判定：求对称中心/轴，对=过。
- 错题归因：中心误用轴公式→机制没懂(T)。

**★3.7 奇偶**
- 先教30秒：代 −x 判。机制：sin 奇、cos 偶。
- 教案动作（备好·口诀）：代 −x，f(−x)=−f(x) 奇、=f(x) 偶；φ 干扰先化标准。示范句："y=sin x 奇，y=cos x 偶"。
- 当堂判定：判奇偶，对=过。
- 错题归因：φ 干扰→知识缺(S)。

**★3.8 y=Asin 解析式**
- 先教30秒：A=峰谷差/2，ω=2π/T，φ 代入零点/最值点。机制：三参数各管振幅/周期/平移。
- 教案动作（备好·步骤）：先定 T 求 ω，再代已知点求 φ（优先代入零点，避免最值歧义）。示范句："峰谷差4 → A=2；T=π → ω=2；过(0,1) → 2sinφ=1 → φ=π/6"。
- 当堂判定：给图求解析式，对=过。
- 错题归因：φ 代错点→计算炸(S)。

**★3.9 变换**
- 先教30秒：先平移后伸缩 vs 先伸缩后平移结果不同。机制：顺序改变括号内结构。
- 教案动作（备好·区分）：sin(x+φ)→sin(ωx+φ)（先平移后伸缩，平移量 φ）；sinωx→sin(ωx+φ)（先伸缩后平移，平移量 φ/ω）。示范句："两种顺序平移量差 ω 倍"。
- 当堂判定：给两种顺序画结果，不同=过。
- 错题归因：顺序错→机制没懂(T)。

**★3.10 整体换元**
- 先教30秒：令 t=ωx+φ 化归标准式，所有性质在 t 上算再换回。机制：降维到标准。
- 教案动作（备好·口诀）：换元后算完必换回 x；区间、最值都先在 t 上求。示范句："令 t=2x+π/3，则 y=sin t，性质全在 t 上"。
- 当堂判定：换元求性质，对=过。
- 错题归因：换回漏→习惯漏(O)。

**▲3.11 四条件翻译**：选学，中档大题启用。开课按需补；判定=能列参数方程；归因=知识缺(S)。
**▲3.12 ω范围**：选学，压轴小题启用。开课按需补；判定=能由点/区间列 ω 不等式；归因=计算炸(S)。

### 板块4 · 恒等变换（焊于 0D 4.1–4.12）

> 总入口 M0：题干含 α±β / 2α / a sinx+b cosx / 证明三角等式 → 进本板块。先拆特殊角 / 提振幅 / 统一名角。
> 总口诀（备好）："和差符号差+和−；cos2α 三式选最省一步；辅助角 φ 看 a,b 符号；证明先统一名与角"。

**★4.1 和差**
- 先教30秒：见非特殊角求和差→拆成特殊角组合（如 15°=45°−30°）。机制：把未知角翻译成已知角。
- 教案动作（备好·口诀）："差+和−"——cos(α−β) 用 +，cos(α+β) 用 −；sin/tan 同号相加。示范句："cos(α−β)=cosαcosβ+sinαsinβ"。
- 当堂判定：给 α±β 求值，对=过。
- 错题归因：符号反（差+和−）→习惯漏(O)。

**★4.2 二倍**
- 先教30秒：见 2α/平方→用二倍；cos2α 按已知选三式之一（cos²−sin² / 2cos²−1 / 1−2sin²）。机制：由已有量选最省一步。
- 教案动作（备好·口诀）：三式选"已知什么就用什么"那式，少算一步；α 范围未知时 cos2α 正负保留 ± 或依范围定。示范句："已知 sinα → cos2α=1−2sin²α（直接）"。
- 当堂判定：给 sin/cos 求 cos2α，对=过。
- 错题归因：三式选错多算→习惯漏(O)；α 范围未知 cos2α 正负→机制没懂(T)。

**★4.3 辅助角**
- 先教30秒：a sinx+b cosx=√(a²+b²) sin(x+φ)，φ 由 a,b 符号定。机制：合成一个波。
- 教案动作（备好·示范句）：提振幅 √(a²+b²)；φ 由 tanφ=b/a 且据 a,b 符号定象限（不只算 tanφ）。示范句："√3 sinx+cosx=2sin(x+π/6)（a>0,b>0→φ 第一象限）"。
- 当堂判定：给 a,b 合成，φ 象限对=过。
- 错题归因：φ 象限错→习惯漏(O)。

**★4.4 化简A型**：即辅助角应用。先教30秒：同 4.3。教案动作（备好）：同 4.3。当堂判定：化简求值，对=过。错题归因：同 4.3。

**★4.12 恒等式证明**
- 先教30秒：统一名/角，左推右或两边化同。机制：化简到同一表达式即证毕。
- 教案动作（备好·口诀）：先切化弦、统一角（倍角化单角）；左→右或两边→中间式。示范句："证 tanα−sinα=tanα·sin²α：左=sinα/cosα−sinα=sinα(1−cosα)/cosα=…=右"。
- 当堂判定：证一道等式，对=过。
- 错题归因：不统一名硬推→机制没懂(T)。

**▲4.5 化简f型 / ▲4.6 构造tan / ▲4.7 s+c,s−c,sc / ▲4.8 三大统一 / ▲4.9 半角 / ▲4.10 积差 / ▲4.11 万能**：选学，综合大题/压轴启用。开课按需补话术；当堂判定=能独立完成该型一题；归因=知识缺(S)为主，计算炸次之。

### 板块5 · 解三角形（焊于 0D 5.1–5.26，最密，补原09弱项）

**总入口 M0**：题干有"边角关系/求边/角/面积/实际测量"→先判用正弦还是余弦。
**总选定理口诀（M1 入口动作，备好）**："两角一边用正弦，三边夹角用余弦，边角混了一起化，求面积就找公式。"

**★5.1 正弦定理**：先教30秒：a/sinA=b/sinB=c/sinC=2R。机制：2R=外接圆直径（直径所对圆周角=90°）。当堂判定：给两角一边求边，对=过。归因：sin 值代错→计算炸(S)。
**★5.2 正弦四变式**：先教30秒：a=2RsinA / sinA=a/2R / a:b:c=sinA:sinB:sinC。机制：边角互化的四种写法。当堂判定：边化角或设 k，对=过。归因：比例当边长直接代→机制没懂(T)。
**★5.3 余弦定理**：先教30秒：c²=a²+b²−2ab cosC 及轮换。机制：勾股定理的推广（C=90°时退化为勾股）。当堂判定：给三边求角，对=过。归因：符号错→计算炸(S)。
**★5.4 余弦变形**：先教30秒：cosC=(a²+b²−c²)/2ab。机制：由边反求角。教案动作：分子顺序 (a²+b²−c²) 对照记。当堂判定：求 cosC，对=过。归因：分子顺序代错→习惯漏(O)。
**★5.5 比例问题**：先教30秒：a:b:c=sinA:sinB:sinC，统一比例设 k。当堂判定：设 k 求边，对=过。归因：比例当边长→机制没懂(T)。
**★5.6 面积五式**：先教30秒：½ab sinC / ½bc sinA / ½ac sinB / pr / abc/4R。机制：夹角的两边乘 sin。教案动作：⚠面积公式必带 sin（易漏写 ½ab）。当堂判定：给边角求面积，带 sin=过。归因：忘×sinC→习惯漏(O)。
**★5.8 外接圆 R**：先教30秒：R=abc/(4S)=a/(2sinA)。机制：接 5.1 的 2R。当堂判定：求 R，对=过。归因：4S 漏→计算炸(S)。
**★5.9 内切圆 r/半周长 p**：先教30秒：r=S/p, p=(a+b+c)/2。机制：面积=半周长×内切圆半径。当堂判定：求 r/p，对=过。归因：p 与周长混淆→习惯漏(O)。
**★5.10 周长/半周长**：先教30秒：L=a+b+c, p=L/2。当堂判定：区分 L 与 p。归因：混淆→习惯漏(O)。
**★5.11 角化边**：先教30秒：用正弦/余弦把角换成边。当堂判定：化边化简，对=过。归因：方向错→机制没懂(T)。
**★5.12 边化角**：先教30秒：用正弦把边换成角。当堂判定：边化角，对=过。归因：方向错→机制没懂(T)。
**★5.13 角的取舍**：先教30秒：SSA 可能多解。机制：大边对大角——边长越大对角越大。教案动作（备好·门板比喻）："门板（长边）撑得开的角度大，短边撑不开那么大角；所以算出的角要和大边对大角对得上，否则舍去。"当堂判定：给 SSA 写出取舍判断过程（不只答案）=过。归因：漏取舍→机制没懂(T)。
**★5.14 SSA两解**：先教30秒：h=b sinA 与 a 比较定解数（a<h 无解；a=h 一解；b>a>h 两解；a≥b 一解）。教案动作（采分点示范句，备好）："∵a=3,b=4,A=30°，b·sinA=2，h=2<a=3<b=4，∴两解。"当堂判定：给 SSA 算 h 比 a 定 0/1/2 解，写过程=过。归因：漏判两解→习惯漏(O)；h 算错→计算炸(S)。
**★5.18 实际应用**：先教30秒：先建系/画示意图。当堂判定：给测量题画图标已知。归因：不画图→读题偏(O)。
**★5.19 测量术语表**：先教30秒：仰角/俯角/方位角/基线/视角/坡度先标图。当堂判定：给术语标图，对=过。归因：术语不懂未标图→读题偏(O)。
**★5.26 大题综合**：先教30秒：正弦+余弦+面积联立。当堂判定：做一道 13分 综合题（走 5.3+5.6 或 5.1+5.15），对=过。归因：综合错→知识缺(S)或计算炸。
**▲5.7 射影定理 / ▲5.15 高线 / ▲5.16 中线角平分线长 / ▲5.17 几何计算**：选学，大题几何综合启用。开课按需补话术；判定=能由 a=b cosC+c cosB 或面积/余弦求线长；归因=知识缺(S)。
**▲5.20 最值(基本不等式) / ▲5.21 最值(三角函数) / ▲5.22 切弦互化最值 / ▲5.23 多边形(含确定△) / ▲5.24 多边形(不含确定△) / ▲5.25 解三角内恒等式**：选学，中档/压轴大题启用（2024T15 面积最值、2023T17 范围）。开课按需补话术；判定=能独立完成该型一题；归因=知识缺(S)/计算炸。
